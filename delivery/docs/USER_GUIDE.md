# 普通用户手册

登录后先通过顶部系统/租户切换进入正确上下文。导航只显示当前角色已发布且有权访问的模块；找不到入口时使用命令中心搜索菜单、模块、待办或记录，不要保存旧的跨系统业务 URL。

## 日常操作

- 列表：筛选、排序、分页、保存视图、收藏、最近访问和允许的批量动作。
- 表单：按页面规则填写，草稿可恢复；提交失败先修正字段错误，网络失败不要重复点击。
- 详情：按权限查看团队、评论、文件、历史、关联记录、流程状态和打印。
- 待办：在待办中心查看任务上下文，执行审批/认领/转交等允许动作并确认业务状态已读回。
- 工作与消息：项目任务、普通任务、日报、提醒、消息已读/归档均与当前平台或系统上下文分离。
- 导入导出：先下载模板并预演，确认错误行后提交；大任务在任务中心查看进度和结果。

移动端使用小屏替代布局完成登录、列表、表单/详情、审批和附件。复杂配置仍使用桌面端。相机或扫码能力取决于浏览器权限和已启用功能；若入口不可见，不应绕过权限上传数据。

遇到无权限、会话过期或上下文变化时返回登录/切换页重新进入。提交、审批和导入均使用幂等保护，但用户仍应以结果读回为准。
