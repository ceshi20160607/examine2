# 管理员手册

## 平台管理员

1. 在平台后台维护平台信息、组织、账户和角色；先预览有效权限再发布。
2. 创建系统后检查初始化任务，进入系统上线引导完成最低配置、普通成员预览和发布检查。
3. 配置身份源、MFA、模型/Agent、平台应用与 SecretRef；高风险动作需原因、确认和审计读回。
4. 系统停用、归档、删除、恢复或迁移前查看影响并备份。
5. 通过日志/体检按 requestId、traceId、actor、对象和结果定位失败。

## 系统管理员

推荐顺序：系统/租户 → 组织成员 → 角色权限 → 模块/字段/字典 → 页面/规则/打印 → Flow → 工作配置 → 数据源/KPI/仪表盘/报表 → 对外应用 → 发布检查。

配置变更先保存草稿，再执行 check/preview；阻断项清零后发布。普通成员预览必须使用成员真实权限，不能用管理员页面成功替代。版本恢复同样需要检查、确认和结果读回。

对外应用仅配置 scope、IP allowlist、限流和 SecretRef。轮换时先创建新版本、更新调用方、验证最近使用，再撤销旧版本。禁止复制明文 secret 到备注、日志或工单。

删除/归档、批量操作、迁移、恢复、权限发布、流程终止等危险操作均先说明影响范围和原因；完成后检查任务状态、审计和业务读回。
