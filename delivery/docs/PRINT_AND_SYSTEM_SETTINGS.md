# 打印、文件与系统设置

打印模板属于系统配置。管理员维护模板基础信息、页面结构、字段绑定、文件/图片组合和启用状态，检查后发布版本；普通成员只使用已发布模板和有权读取的字段。生成 PDF 前端预览不能替代后端权限检查。

文件字段支持上传、下载、预览和打印组合。文件大小、类型、对象归属和当前记录权限由后端校验；对象存储凭证只通过 SecretRef 配置。删除记录或文件前应检查引用影响和恢复策略。

系统设置包括名称/标识、租户、域名、配额、存储、安全、身份继承、消息渠道和发布策略。修改会影响登录、文件、通知或对外集成的设置时，先在测试环境验证，再通过草稿/check/publish 或明确确认动作生效。生产秘密不得填写到普通文本字段。

打印异常依次检查：模板是否发布、字段权限、文件是否存在、字体/图片格式、PDF 响应状态和 traceId。系统设置异常优先查看配置版本、依赖健康和应用日志，不直接修改数据库绕过发布流程。
