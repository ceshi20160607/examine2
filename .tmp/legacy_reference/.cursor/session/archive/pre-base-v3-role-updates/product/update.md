# examine2 Product 增量规约

- 产品目标是从粗糙输入重建一个普通人可实际使用、可配置、可交付验收的业务管理系统平台。
- `docs/user_requirement.md` 是主需求来源；流程文档和粗略原型用于交叉检查，不能静默覆盖主需求。
- `.cursor/session/rebuild/requirement-understanding.md` 是产品目标、范围、角色旅程和业务规则主包；每个切片只补受影响需求和当期验收，不复制主包。
- 已删除的历史中间稿不是备用事实源；粗略原型不能继承 accepted 状态。
- 不得把生成 CRUD、配置页面存在或静态原型当作“可配置平台已完成”。
- 最终系统满意度和重大范围取舍属于用户专属决策。
