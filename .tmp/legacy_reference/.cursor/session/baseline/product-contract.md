# 产品与页面冻结合同

## 1. 产品区域

产品固定分为四个使用区域和一个后台区域：

| 区域 | 使用者 | 只负责 |
|---|---|---|
| 公共认证域 | 未登录用户 | 登录、注册、找回/重置密码、SSO/MFA 回调、无成员申请状态 |
| 平台工作区 | 平台账号、平台管理员 | 我的系统、平台 Flow、平台对外应用、平台日志；待办和消息位于顶部 |
| 系统运行台 | 当前系统成员 | 仪表盘、模块组、模块数据、流程任务、工作协作和记录详情 |
| 系统后台 | 系统拥有者、系统管理员 | 系统、组织权限、业务建模、Flow 配置、仪表盘、数据源、对外应用和日志 |
| 平台后台 | 平台管理员、运维 | 系统/租户、平台组织账号、平台授权、全局配置、身份源、健康、版本和部署 |

平台身份不能代替系统成员身份。打开任何系统业务页前必须生成完整 `SystemSwitchContext`。

## 2. 权威导航与路由

### 2.1 公共认证域

| 页面 | 路由 | 阶段 |
|---|---|---|
| 登录 | `/login` | P1 |
| 注册并创建首个系统 | `/register` | P1 |
| 忘记密码 | `/auth/forgot` | P2 账号安全批次 |
| 重置密码 | `/auth/reset` | P2 账号安全批次 |
| SSO 回调/MFA | `/auth/sso/*`、`/auth/mfa` | P6 |
| 无成员申请/等待审核 | `/no-member/:systemId` | P6 |

旧 `/auth/login` 只允许兼容重定向到 `/login`，不得保留第二套登录页面。

### 2.2 平台工作区

侧栏固定顺序：

1. 我的系统 `/platform/systems`
2. Flow `/platform/flows`（P4 启用）
3. 应用 `/platform/applications`（P4 启用，含义是平台对外应用）
4. 日志 `/platform/logs`（P7 启用）

顶部固定工具：待办、消息、系统切换、用户菜单、平台后台入口。未交付功能不显示占位菜单。

登录默认落点固定为 `/platform/systems`；“我的工作台”不再建立第二个同义首页。P5 的平台工作能力从顶部“工作”入口进入，不增加另一个首页或运营导航。

### 2.3 系统运行台

```text
顶部主导航：仪表盘 | 动态模块组...
左侧二级导航：当前模块组下的模块
顶部工具：工作 | 流程 | 待办 | 消息 | 系统切换 | 用户 | 系统后台
内容区：仪表盘、模块列表/表单、右侧详情工作区
```

- 仪表盘：`/systems/:systemId/dashboard`。
- 模块列表：`/systems/:systemId/modules/:moduleCode`。
- 工作中心：`/systems/:systemId/work`，P5 启用，内部承载项目、任务、日报和日历。
- 流程中心：`/systems/:systemId/flows`，P4 启用，内部承载待办、抄送、申请和实例。
- 待办、消息使用顶部入口，不在侧栏重复。
- 文件默认进入记录详情标签或系统后台文件中心；没有独立用户任务时不增加运行态一级导航。
- AI Agent 的普通用户入口是右侧助手；只有 Agent 策略管理进入系统后台独立页面。

系统切换后的落点顺序固定为：

1. 有权限且存在已发布默认仪表盘：进入仪表盘。
2. 没有已发布内容且当前成员是系统管理员：进入 `/systems/:systemId/admin/onboarding`。
3. 普通成员：进入第一个有权限的已发布模块。
4. 没有任何可访问内容：显示明确无权限/待配置状态，不进入空白 workbench。
5. 系统停用：普通成员拒绝；系统管理员仅获得 `ADMIN_SETTINGS_ONLY` 受限上下文并进入设置。

### 2.4 系统后台

后台一级分组固定为：

- 系统：信息与访问、登录与统一认证、参数与功能开关、租户。
- 组织与权限：部门成员、角色权限、无成员访问申请。
- 业务建模：配置中心内按模块组、模块、字段、页面、菜单、字典分步骤，不拆成五个同权重一级导航。
- 自动化：Flow 配置、工作配置。
- 数据展示：仪表盘、数据源、KPI 配置；KPI 运行结果由仪表盘承接。
- 集成：对外应用/OpenAPI、消息模板、文件。
- 智能能力：Agent 策略。
- 审计：登录日志、业务日志、接口日志。

## 3. 管理列表合同

```text
标题行：模块标题                              导入  导出  [新建]
工具行：[模糊搜索________________] [高级筛选]
选中后：已选 N 项 | 批量编辑/转移/删除/导出
表格：序号 | 勾选 | 已配置业务列 | 状态 | 更新时间 | 差异化行操作
行点击：右侧详情工作区
详情标签：概览 | 关联数据 | 评论 | 文件 | 历史（只显示已启用能力）
```

- 页头最多一个 primary；导入导出是紧凑次级动作。
- 搜索只做快速文本检索；高级筛选只做结构化条件。
- 保存视图、列表场景、草稿不默认显示，必须由后续模块合同指定独立位置和任务。
- 批量动作只在有选择时出现。
- 行点击打开详情；操作列禁止“查看/详情”。
- 关注若后续进入模块需求，只能放在记录行或详情，不得放模块页头。
- “导出当前筛选”和“导出已选记录”是两个明确动作，不能混成含糊“全部导出”。
- 详情保留列表上下文，采用右侧标签工作区；不允许把关联、评论、文件、历史纵向堆叠。
- 加载、空、错误、无权限均有专属状态；分页、筛选和批量动作必须产生可见结果。

## 4. 设计器合同

- 仪表盘：可视化拖拽、调整尺寸、排序、绑定数据源、预览、发布是主路径；JSON 只能高级导入导出或诊断。
- 字段设计：左字段类型、中预览、右专属属性。
- 页面设计：左组件、中预览、右配置；列表、表单和详情分别配置。
- Flow：全屏画布、拖拽节点/连线、右侧节点专属属性、发布检查；不得以 JSON 编辑为普通入口。

## 5. 明确冻结或删除

- `/systems/:systemId/operations` 及“运营”导航。
- `/systems/:systemId/reports/:reportCode?` 独立报表运行入口。
- `/systems/:systemId/admin/reports` 报表工作室。
- 模块收藏、旧收藏面板以及把收藏改名为关注的做法。
- 旧 `SystemWorkbenchView`、旧大工具栏、重复详情按钮和 default/generic drawer。
- 独立 KPI 运行页；KPI 作为配置能力和仪表盘组件存在。
- 未实现功能的占位导航、占位卡片和假成功按钮。

冻结表示旧代码只可读；新入口验收通过后再单独删除或重定向，不在当前合同阶段修改功能代码。

## 6. 阶段关系

| 产品大期 | 机器交付期 | 可用结果 |
|---|---|---|
| 第一期 | P1 | 干净启动、默认 admin、登录/注册、我的系统、系统上下文和系统壳 |
| 第二期 | P2 + P3 | 平台/组织/权限、模块配置发布、运行 CRUD、右侧详情和可视化仪表盘 |
| 第三期 | P4 | Flow 配置与处理、平台/系统对外应用 |
| 第四期 | P5 + P6 | 工作、任务、日报、消息、文件、导入导出、丰富配置和受控 AI |
| 收口 | P7 | 响应式、可访问性、安装升级、备份恢复、发布和用户验收 |

未来阶段只冻结导航、数据所有权和出口结果；仅当前阶段及紧邻下一阶段允许生成原子 coding task。
