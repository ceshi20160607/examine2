# Unexamine 交付文档

本目录随版本化部署包交付。管理员先按[部署和恢复说明](../README.md)安装并检查服务，再按角色使用以下说明。页面名称以当前 Web 管理端、运行台和响应式移动端为准；页面上实际可见的动作取决于已发布配置和当前权限。

- [管理员手册](administrator.md)：系统、租户、模块、角色和 Flow 的配置与发布。
- [普通用户手册](member.md)：记录、审批、附件、打印、导入导出及手机使用。
- [应用访问接入说明](application-access.md)：系统间调用与外部签名调用。
- [打印模板和系统设置说明](printing-and-settings.md)：模板发布、权限、版本与 PDF。
- [常见问题和错误排查](troubleshooting.md)：登录、权限、迁移、文件与应用调用。

数据库三份脚本的职责见部署包中的 `db/README.md`；环境变量、启停、备份和恢复命令见[部署说明](../README.md)。
