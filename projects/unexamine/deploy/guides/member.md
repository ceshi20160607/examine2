# 普通成员业务操作手册

成员在系统运行台处理已获权的业务记录。桌面与手机使用同一 Web 页面和同一份发布配置；当前工作空间、模块角色和记录负责人范围共同决定可见数据。

## 进入系统并处理记录

1. 登录平台工作区，从“我的系统”进入获权系统。多租户系统先确认顶部显示的工作空间；切换工作空间后重新核对列表。
2. 在“业务模块”选择模块，用“新建”填写标题、负责人和模块字段，保存后在列表找到记录。记录详情可查看当前字段和历史；“编辑”保存后刷新列表与详情确认结果。
3. 使用搜索和筛选查找记录。看不到预期记录时先检查当前工作空间、状态筛选和负责人范围；无权记录不会因为知道记录地址而可见。
4. 手机窄屏以记录卡片显示列表。点卡片进入详情；新建、编辑、附件、打印和导出仍使用页面上的同一套业务动作。

## 审批、文件和导出

记录出现“发起审批”时，提交后审批人可在“待办”打开流程并选择同意或拒绝。发起人从记录或流程页查看状态；重复提交和无权办理会被拒绝。审批未完成时，按页面提示处理记录编辑限制。

附件在编辑记录时上传并随记录保存，详情“附件”页按当前字段权限展示。上传后重新打开详情，核对文件名并尝试下载；不应把本地选择文件视作已保存成功。

有“打印”权限且模板已发布时，从详情选择模板版本，生成后预览或下载 PDF。导出从列表页打开，先确认筛选结果和字段，再创建任务；结果文件仅供提交人下载。导入前按页面模板准备文件，先看预检错误，再提交有效行。

## 异常处理

遇到权限拒绝，向管理员提供系统、工作空间、模块、动作、记录标题及页面返回的错误码，不要共享密码或应用密钥。上传或导出失败时先在任务状态页查看失败原因；刷新后仍失败再按[排查说明](troubleshooting.md)提交请求标识。
