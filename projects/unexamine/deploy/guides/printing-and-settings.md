# 打印模板和系统设置说明

业务打印依赖模块已发布的 PRINT 动作、当前成员的记录与字段权限，以及目标租户中已发布的打印模板。模板草稿、历史版本和生成的 PDF 是不同对象。

## 发布和使用模板

1. 系统管理员进入“系统管理 → 其他业务参数 → 打印模板”，选择目标模块，配置纸张、方向、版面、字段和签章区域；通过发布检查后发布版本。
2. 在“模板配置 → 模块搭建 → 模块动作”发布打印动作，并在“角色权限”给目标角色授予打印及所需字段的页面、文件读取权限。跨工作空间使用时分别核对目标工作空间的发布和授权。
3. 普通成员从记录详情打开“打印”，选择已发布模板版本，生成 PDF 后预览或下载。打印任务保存所用模板版本和文件引用；页面预览与下载使用同一任务快照。

模板更新不会重写旧任务。旧任务是否可下载还取决于配套文件存储字节是否仍在；迁移或恢复时必须同时备份数据库和文件目录，并抽查历史 PDF 下载。只有任务元数据而没有文件字节时，先恢复配套文件备份，再判断能否重试；不要直接删除历史记录。

## 系统设置边界

系统后台修改租户模式、模块、权限、Flow 和应用时，先查看影响提示并核对草稿，再发布。停用动作或撤销权限后应以普通成员身份重新打开记录，检查打印入口、字段和下载是否按当前授权变化。配置版本、数据库版本和备份要求见[部署说明](../README.md)。
