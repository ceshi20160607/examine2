# 常见问题和错误排查说明

排查时先记录发生时间、环境、系统与工作空间、页面或接口、动作、响应码和请求标识；不要把密码、重置链接、应用签名密钥或数据库凭据写入日志和工单。

| 现象 | 核对顺序 |
| --- | --- |
| 登录后看不到系统 | 检查账号状态、系统成员资格、目标租户是否可见，再检查角色发布版本。 |
| 看得到模块却看不到记录 | 检查工作空间、筛选、记录状态、负责人及角色数据范围；用管理员权限核对目标记录是否仍存在。 |
| 审批待办不可办理 | 检查 Flow 是否已发布并绑定当前动作、任务是否仍待处理、当前账号是否为指派审批人。 |
| 附件或旧 PDF 无法下载 | 核对文件对象引用与文件目录中的实际字节、当前字段/记录权限，以及数据库和文件备份是否来自同一恢复点。 |
| 导出任务无结果 | 检查当前筛选、导出动作及字段权限、任务失败明细和存储目录；结果只能由任务提交人下载。 |
| 应用调用被拒绝 | 核对应用是否启用、授权版本、目标系统和租户、动作与字段、数据范围、凭据版本、时钟及签名原文；再查调用日志错误码。 |
| 服务启动失败或页面无响应 | 先运行 `scripts/status.ps1`，检查服务日志、MySQL 和 Redis 连通、环境文件及密钥注入，再看 Flyway 历史是否有失败迁移。 |

发布脚本在切换服务前校验 JAR 和前端文件摘要、目标数据库版本与升级备份。若数据库已迁移但新服务启动失败，按 `runtime/last-deployment.json` 的恢复要求处理，不要直接把旧 JAR 指向新结构。完整备份用 `scripts/backup.ps1`，隔离恢复用 `scripts/restore-drill.ps1`；验证结果要与数据库、文件和配置快照同时核对。

开发环境的本地密码重置投递箱只供服务操作员读取，不代表生产邮件已送达。生产环境须配置真实 HTTPS 投递服务并验证邮箱；未配置时接口返回明确错误。
