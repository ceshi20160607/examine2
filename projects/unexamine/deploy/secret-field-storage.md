# 密码/密钥字段存储与升级

当前字段运行链使用既有 `app.security.application-secret-master-key` 配置，运行字段与应用签名密钥分别派生加密密钥。主密钥必须至少 32 个字符，由部署环境提供并妥善备份；不要写入业务配置、验收材料或日志。缺少主密钥时不能正常读写受保护值。

`biz_record_value.value_text` 保存 `runtime-secret:v1:` 格式的 AES-GCM 密文，附加认证数据绑定实际记录 ID 和字段 ID。统一动作意图中的字段值同样加密，绑定原系统、数据租户、模块、版本、动作、记录、发起人和追踪号。批准时只在锁定原动作的事务内部恢复输入。流程变量和业务快照只接收脱敏值，审计与字段历史不保存明文。不得复制密文到另一个字段或记录作为迁移办法。

本轮升级前对当前运行数据库核对的 SECRET 值为 0，因此没有覆盖历史值或执行数据删除。升级其他环境之前，需要先统计 `biz_record_value` 中 `value_type = 'SECRET'` 的值，以及关联的未结束动作、流程快照、审计和历史中的旧明文。不能仅凭本环境的零值结论跳过其他环境检查。

如果发现旧明文，采用停写后的受控离线迁移：先备份数据库与原主密钥；保留所有记录、字段和动作 ID；用相同的 `RuntimeSecretCipher` 及对应附加认证数据转换旧字段和未结束动作意图；清理查询投影中的旧明文，对流程快照和审计历史按字段定义脱敏。逐项核对数量、作用域、解密结果与未结束动作的可恢复性，再恢复写入。迁移过程不得把明文或主密钥打印到日志。当前代码没有自动旧明文转换工具，不允许把错误密文或旧明文自动当成正常值读取。

主密钥变更也需要受控重新加密；直接替换部署主密钥会使原值不可解密。当前没有在线主密钥轮换流程。损坏、作用域不匹配或不可解密的值返回 `SECRET_VALUE_UNAVAILABLE`，需要恢复正确密钥或从备份修复，不能删表重建。

列表与写入回执默认脱敏；详情读取必须有当前动作权限，且贡献角色对该具体字段及渠道都显式可读、没有脱敏或拒绝策略。浏览器编辑框不预填密码，遗漏字段键表示保留，`null` 表示清空可选字段。安全默认值引用以及应用、导出等完整消费方授权仍有独立执行步骤，本说明不表示这些消费方已经验收。
