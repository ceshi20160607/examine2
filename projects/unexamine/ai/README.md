# 项目 AI 控制面

这里保存“如何把需求变成可用系统”的项目事实，不保存产品源码。唯一产品需求仍是 `../../../docs/user_requirement.md`。

目录职责：

- `requirements/`：需求源索引、全量互斥分析包、原子需求和用例。
- `architecture/`：产品层级、运行时元数据、权限、租户和代码边界。
- `planning/`：能力唯一归属、原子任务、依赖、现有代码评估和最多 240 分钟的周期排期。
- `agents/`：总控及各角色的具体任务单；角色只执行这里分配的任务。
- `decisions/`：需求冲突、未决问题和用户/总控裁决记录。
- `status/`：只声明当前 9 关口中的稳定 ID；数量、比例和审计状态由工具从仓库证据计算，不接受自报完成。
- `evidence/`：按周期保存测试、MySQL 读回、API 和真实页面入口证据。

当前处于 `G01_REQUIREMENTS`。在原子任务、依赖和现有代码评估完成前，不生成额外阶段和周期排期，也不把候选代码折算成产品完成率。
