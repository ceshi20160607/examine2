## Q-20260817-001 低代码自定义模块是否生成物理业务表

- 状态：已关闭
- 背景：系统后台允许用户通过页面创建模块、字段、页面和动作，需要确定运行时数据存储与代码生成边界。
- 影响：数据库模型、发布机制、查询索引、Base 代码生成和系统升级。
- 建议方案：固定产品能力使用物理表；低代码自定义模块统一使用元数据、通用业务主记录、字段值、查询索引和独立关联表，不在运行时生成 Java 代码或物理业务表。
- 最终答案：采用建议方案；不设置少数自定义模块升级独立物理表的分支。
- 裁决：用户，2026-08-17。

## Q-20260817-002 移动端交付形式

- 状态：已关闭
- 背景：需求要求移动端重点支持使用能力，但没有要求独立安装包或原生能力。
- 影响：前端工程数量、交付周期、页面适配和测试矩阵。
- 建议方案：桌面端与移动端使用同一套 Vue 应用和配置，通过响应式页面交付，功能完成后统一 hardening。
- 最终答案：采用建议方案，不开发独立原生移动 App。
- 裁决：用户，2026-08-17。

## Q-20260817-003 系统之间及平台内外如何通信

- 状态：已关闭
- 背景：每个自定义系统相互隔离，但系统之间、平台外部与系统、平台外部与 Flow 仍需要受控通信。
- 影响：应用边界、凭证、授权、租户上下文、调用审计和 Flow 开放方式。
- 建议方案：应用作为唯一授权桥梁；调用目标系统能力时由目标系统应用授权，调用平台 Flow 时由平台应用授权。
- 最终答案：采用建议方案。系统内部的单租户、多租户或组织模式不自动产生跨系统权限；应用仍需校验目标资源、动作、字段、数据、系统和租户范围。
- 裁决：用户，2026-08-17。
