## Baseline Interpretation

The clean rebuild target is a usable no-code/custom business system where:

- admins can create and configure business systems;
- normal users can use configured modules, work, todo, messages, and AI assistance;
- Flow can orchestrate internal/external workflows;
- Application is the authorization gateway for exposing Flow or system services;
- backend/admin configuration controls dashboards, modules, flow, applications, dictionaries, work, AI, data sources, and logs.

## Non-Completion Boundaries

- A static prototype page is not completion.
- Generated CRUD is not completion.
- API 200 alone is not completion.
- Old `RECOVERY-R*` PASS evidence is not clean rebuild completion.
- User-facing acceptance remains open until a real runnable system proves role journeys and the user signs off.
