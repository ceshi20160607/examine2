### 2.1 来源冲突规则

1. 用户最新落盘决定高于所有旧文档。
2. `user_requirement.md` 附录 A 高于正文中被澄清的旧模型。
3. `temp_flow.md` 和人读版 HTML 用于发现遗漏，不可反向扩大或改变主需求。
4. 原型只能补充交互问题，不能用截图或已有页面定义功能范围。
5. 旧代码、旧 evidence、旧 accepted/pass 状态不再是当前需求或完成证据。

## 3. 最终产品目标

examine2 最终交付一个可配置业务系统平台，使不会写代码的管理员能够创建系统、组织模块组和模块、配置字段/页面/权限/流程/数据源/仪表盘/打印/导入导出/对外应用并发布；普通成员能够从正确的系统和租户上下文进入业务运行态，完成数据、审批、工作、消息和协作；外部系统能够在应用授权、签名、幂等、限流和审计边界内安全接入；运维人员能够部署、检查、升级、备份、恢复和排障。

最终结果不是低代码演示、接口调试后台、静态原型或生成 CRUD，而是普通企业团队可以长期使用、可扩展、可维护、可交付验收的运行系统。

### 4.2 明确不在产品目标内（OUT）

- 不做重型行业 ERP/MES 套件；通过通用建模、流程、KPI、打印和仪表盘覆盖轻量场景。
- 不把“应用”作为模块父级；模块必须归属模块组，应用只承担对外访问授权。
- 不允许平台身份绕过 `SystemSwitchContext` 直接读写系统业务数据。
- 不允许 AI 自动绕过人工确认、权限、校验、流程和审计写入数据。
- 不在移动端承担字段、页面、流程和复杂权限设计等重配置工作。
- 不使用旧代码、旧原型、旧批次或旧截图作为当前完成证明。
- 当前技术要求明确不引入 Quartz、消息队列或复杂任务平台；后台任务使用 Redis 和本地 event 扩展。

## 8. 全局业务规则

| rule_id | 规则 | 影响范围 |
|---|---|---|
| RULE-001 | 平台层和系统层严格分离；平台运维身份不能自动获得系统业务权限 | 身份、路由、权限、日志 |
| RULE-002 | 系统业务上下文以 account + systemMember + tenant + permission snapshot 为准，不能信任前端伪造 Header | 所有系统 API |
| RULE-003 | 模块组组织模块导航；对外应用只组织外部授权；业务数据不以 appId 或模块组为父级 | 模型、路由、表结构 |
| RULE-004 | 所有配置能力区分草稿、发布版本和历史版本；运行态只读发布版本 | 字段、页面、流程、字典、打印、仪表盘、数据源、权限 |
| RULE-005 | 流程运行、打印历史和关键业务动作保存当时配置/字段/权限快照 | 历史可解释性 |
| RULE-006 | 前端权限用于体验，服务端权限和查询层数据范围是最终边界 | UI/API/数据 |
| RULE-007 | 同一对象同一上下文只有一个主详情入口；业务列表整行打开详情，差异动作使用按钮 | 列表/详情交互 |
| RULE-008 | 列表、看板、日历是同一数据集合的互斥视图，不生成重复对象 | 工作管理和通用视图 |
| RULE-009 | 关键按钮必须进入保存、检查、任务、日志或专属结果链路，禁止泛化假成功 | 全部用户动作 |
| RULE-010 | 密钥使用引用和版本，明文只在必要创建时一次展示，不进入页面回显/日志/文档 | SSO/OpenAPI/AI/Webhook |
| RULE-011 | AI 查询和写入继承当前身份/权限/脱敏；写入和高风险动作必须人工确认 | AI Agent |
| RULE-012 | 导入先预演后确认，导入批次可解释并在满足条件时回滚；导出大数据走后台作业 | 导入导出 |
| RULE-013 | 保存业务记录是跨主记录/字段/子表/附件/关联/团队/历史/流程的事务性业务动作 | 数据运行态 |
| RULE-014 | 状态语义统一：灰低强调、蓝进行、橙待关注、绿成功、红异常/阻断 | UI/字典/工作/流程 |
| RULE-015 | 内部 API 与 OpenAPI 分离，平台 API 与系统 API 分离，所有错误和日志携带 requestId/traceId | API/运维 |
| RULE-016 | 生成代码只做贴表基础设施；业务服务、权限、事务、状态、副作用和读回必须手写并独立验收 | 后端工程 |
| RULE-017 | 工程证据与用户签字分离；任何 agent、脚本和历史结果都不能设置用户已验收 | 最终完成 |
| RULE-018 | 四套壳按角色和上下文独立：平台工作台、平台后台、系统业务页、系统后台；切换时完整刷新导航和权限 | 前端路由、API 上下文、用户体验 |
