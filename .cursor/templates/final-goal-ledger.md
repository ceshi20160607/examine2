## Non-Completion Cases

The goal is not complete if any of these are true:

- A page exists but the role cannot finish the job.
- An API works but the deployed frontend is not bound to it.
- Generated CRUD exists but coded business behavior is missing.
- A script passes without role-level journey evidence.
- User signoff is missing for a subjective usability claim.
