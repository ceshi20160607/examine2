# 名词表（L0）

| 名词 | 是什么 | 不是什么 |
|------|--------|----------|
| **平台层** | 管理所有自定义系统、平台账号、SSO、平台 Flow、平台 API 产品、跨系统日志 | 某个系统内的业务模块数据 |
| **自定义系统** | 租户/客户创建的业务应用空间（字段、页面、流程、组织） | 平台本身；不是 Docker 里的「系统进程」 |
| **租户 Tenant** | 数据与配置隔离边界；多租户模式下系统内再分租户 | 不等于「自定义系统」（一系统可单租户或多租户） |
| **单租户模式** | 系统内不展示租户切换，全员同一数据空间 | 不是「只有一个用户」 |
| **多租户模式** | 系统内顶栏租户切换；数据带 tenantId | 不是平台层的多系统 |
| **模块组** | 运行态顶栏分组 + 左栏模块列表 | 字段分组；不是对外应用 |
| **模块** | 业务对象（表+页面+权限） | 不是平台 API 路由 |
| **平台 Flow** | 跨系统/平台级编排（事件、Webhook、大流程） | 不是某模块内的审批流 |
| **系统 Flow** | 绑定模块的审批/自动化流 | 不是平台 Flow |
| **平台对外应用** | API 产品：凭证、scope、供**外部系统调用平台能力** | 不是自定义系统内的业务菜单 |
| **系统对外应用** | 某自定义系统对外的 API 入口（暴露本系统模块数据） | 不是模块的父容器 |
| **API 控制台 Console** | 配置路由、映射、发布、限流（Kong 管理端心智） | 不是开发者文档 Portal |
| **开发者 Portal** | 外部开发者看文档、申请订阅（P1 可简） | 不是管理员配路由的地方 |
| **SSO** | OIDC/SAML 企业登录；平台统一 IdP 配置 | 不是业务模块里的「单点字段」 |
| **组织架构** | 部门树 + 成员 + 岗位（系统内） | 不是平台用户表本身 |
| **权限** | 菜单/操作/数据范围/字段（系统内角色） | 不是 API scope（但有关联） |
| **待办/消息** | 顶栏全局入口；流程与系统通知 | 不是侧栏重复菜单 |
