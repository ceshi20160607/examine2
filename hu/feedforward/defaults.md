# Agent 默认补全规则（用户未指定时）

用户说「你定」「按常规」时，Agent 直接采用下列默认，并写入 `docs/decisions/resolution.md` 为 `AUTO-xxx`。

## 产品形态

| 场景 | 默认 |
|------|------|
| 「可配置业务系统 / 低代码 / OA / CRM」 | 平台层 + 自定义系统层 + 运行态 三层 |
| 「单租户后台管理」 | 管理态 + 运行态 两层，无平台多系统 |
| 「对外 API 产品」 | 管理端 + 开发者凭证页 + 调用日志 |

## 导航

| 项 | 默认 |
|----|------|
| 待办/消息 | 顶栏图标 + 角标；侧栏不重复文字菜单 |
| 列表页 | 标题行 + 单行工具栏；勾选后才出现批量条（≤40px） |
| 详情 | 列表行点击 → 右侧抽屉；复杂详情可整页 |
| 新建 | 全页一个主按钮 |

## 列表页（标准业务表）

必须包含（Design 期原型须可见）：

- 快捷搜索 + 高级筛选抽屉
- 场景/视图（下拉或少量 chip，不横铺整行）
- 列设置（显隐、顺序、固定列）
- 序号列 + 勾选列
- 工具栏：导入、全部导出；勾选后：导出选中、批量编辑/删除/转移（按权限 disabled + tooltip）
- 1440×900 首屏 ≥ 8 行业务数据

## 配置链（可配置系统默认顺序）

```
基础参数 → 字典/主数据 → 数据源(若有仪表盘) → 分组/模块 → 字段/页面 → 权限 → 发布 → 运行态验证
```

「分组」默认 = 运行态顶栏分组 + 左栏模块列表（**不是**字段分组，**不是**应用下挂模块，除非用户明确要求容器模型）。

## 账号

| 项 | 默认 |
|----|------|
| 账号体系 | 平台统一用户表；系统内成员 = 平台用户 + 组织扩展 |
| 注册 | 可注册并创建第一个系统/租户，注册人 = 超管 |
| 演示账号 | admin 配置者 + user 业务使用者 |

## 权限

- 菜单 + 操作 + 数据范围；字段级权限在「角色配置页」
- 平台角色与系统角色分页，不混 Tab
- 导出 = 页面动作权限，无独立导出中心

## 流程（若需求含审批）

- 系统后台：流程绑定模块 + 触发事件
- 运行态：待办列表 + 审批详情（业务数据 + 流程图 + 历史）
- 设计器：画布 + 右侧节点属性（非 JSON 主编辑）

## 对外集成（若需求含 API）

- 凭证 appKey/secret（secret 只显示一次）
- scope 授权 + 调用日志
- 与业务模块解耦的「对外应用」入口

## 原型风格

- 中文；现代企业后台（Ant Design / Naive 气质）
- 禁止：大面积渐变营销页、接口调试风、主内容 JSON
- 演示数据：一条完整垂直业务（如「车系统」「订单系统」），字段名业务化

## 无代码 + 多租户 + SSO + API 平台（关键词触发）

当 `需求.md` 含 **SSO / 多租户 / 对外 API / 平台工作流** 时，L2 除默认页表外 **必须** 含：

| 页 | 用途 |
|----|------|
| plat-admin-tenants | 平台租户 |
| plat-admin-sso | IdP/OIDC |
| plat-admin-api-console | 路由+映射+发布（Kong Console 心智） |
| sys-admin-tenant | 系统单/多租户模式 |
| portal-* | P1 开发者门户占位 |

对照：`.cursor/knowledge/external-references.md`

## MVP 切刀（默认不做 Design 独立页）

- KPI 深度、打印模板可视化、Excel 导入向导全流程、Agent 问数、多租户切换 UI、拖拽自由布局仪表盘
- 以上可在 design-scope 标「Build 后期」，原型仅工具栏占位或省略

## 冲突时

defaults 服从 `docs/decisions/resolution.md` 用户 RES；用户 RES 服从 `rough-input.md` 明确原话。
