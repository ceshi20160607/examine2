# Unexamine 基础需求梳理

## 已明确的依据与边界

- [表意义.md](表意义.md) 中的 94 张表及其中文用途，是本轮数据模型的原始定义。建表时使用原表名，不改名、不合并、不用别的表代替；其中 `un_module_scence` 的拼写也保持原样。
- 用户要求舍弃先前重构产生的复杂模型与工程编排，保留通用代码生成工具，并参考 `template_base` 的 agents/rules；开发时不过度封装。
- 这 94 张表作为当前项目基础实现的整体表边界。字段参数先参考 [old_table1.sql](old_table1.sql) 中可用的旧设计；缺少的字段按当前功能与目标补全。旧 SQL 中的数据和删表语句绝不执行。
- 表关系保持实现所需的简单程度，不引入为未来扩展而设的复杂关系和抽象。
- 后端先完成支撑基础功能所需的接口并接受验收，之后再开发前端。接口须覆盖列表、表头与排序、场景和场景配置、表单字段配置、新建与保存等完整业务动作；不等用户逐个列举。
- 任务理解、拆分、依赖与可以并行的工作由工程框架和开发过程承担。共享数据库迁移与接口合同保持串行确认，互不依赖的业务域可以并行。
- 本机 3306 上历史项目库已获准删除；新实现只使用重新创建的项目库。MySQL 必需的系统库保留。
- 清理前的需求汇编、表模型、代码、验收记录和任务编排都不是本轮需求依据。若本文与《表意义.md》冲突，以后者为准。

## 按表用途整理的业务范围

以下是对表用途的功能归类，用于检查理解；具体操作、字段和表间关系仍需结合实际业务确认。

1. **平台管理**：平台账号登录；管理平台成员、部门、角色、菜单、数据权限、配置、登录与操作日志、消息。使用 `un_plat_*` 原表。
2. **公共能力**：文件、公告和 AI 配置分别使用 `un_common_file`、`un_common_notice`、`un_common_ai`。
3. **业务系统与租户**：平台创建业务系统；系统管理租户、成员、部门、菜单、角色、数据权限、配置、日志和消息。使用 `un_sys_*` 原表。系统成员与租户成员按原表分别处理。
4. **可配置模块**：管理员配置模块分组、模块、字典、字段、菜单、动作、规则、查询字段、租户扩展、场景、成员及关联；用户使用模块记录和扩展数据，并能查看变动。使用 `un_module_*` 原表。模块审批 `un_module_examine` 与模块流程 `un_module_flow` 保持两个独立概念。
5. **流程**：配置流程、节点、连线、版本和绑定；运行实例、待办、候选人、操作、异常、事件及定时任务。使用 `un_flow*` 原表。流程版本发布后不可变；实现时需要验证发布和运行行为。
6. **审批**：配置审批、分组、高级配置、异常处理、人员、节点和节点字段；运行审批实例及节点人员。使用 `un_examine*` 原表。审批与通用流程各自保留数据边界，不用一套表覆盖另一套。
7. **应用接入**：受控访问应用及其事件配置使用 `un_app`、`un_app_event`。
8. **工作管理**：项目、参与人、任务组、任务、任务字段、任务成员、历史、每日日志及评论使用 `un_work_*` 原表。
9. **数据展示**：仪表盘、组件、组件字段、使用人员使用 `un_dashboard*`；数据源及配置使用 `un_data_source*`；KPI 与用户使用 `un_kpi*`。
10. **打印**：打印模板使用 `un_print`。

## 当前实现状态与实施选择

- 采用一个 Spring Boot 后端与 MyBatis-Plus 生成器；前端实现暂停到后端接口验收之后。技术选型属于工程选择，不是《表意义.md》规定。
- 本轮已按 94 张原名表建成 `unexamine_r15` 隔离库，后端基础接口正在按真实 HTTP、持久化、授权和失败结果验收；已验收及未完成范围分别记录于 `docs/backend-acceptance.md` 和 `docs/backend-plan.md`。
- 通用生成器在各业务模块的 `base` 包生成 Entity、Mapper、IService 和 ServiceImpl，提供标准基础 CRUD。Controller 通过 Service 调用；`manage` 只写特殊逻辑、权限与业务编排，不重复包装基础 CRUD。

## 实施验收

- 先按全部 94 张表的用途梳理业务边界与必要字段，再创建有实际用途的表、生成 Base，最后实现后端业务接口；不造只有 `id` 的空壳表。后端验收完成后才继续前端。
- 后端阶段检查真实 HTTP 请求、数据库持久化、授权边界和失败处理；后端验收后开发前端，再检查实际页面行为。编译成功或接口返回 200 不代表功能完成。
- SQL 中表和每个字段都写中文备注；时间列用 `*_time`，Java 属性用 `*Time`。对已有数据做字段变更时提供迁移，不直接删表重建。
