入口能力

从这里开始不能跑偏

登录

  • 字段：账号、密码、验证码、MFA、身份源。
  • 动作：登录、SSO 登录、注册、忘记密码。
  • 状态：加载、失败、锁定、过期、无权限、需二次验证。

注册并建系统

  • 字段：账号、姓名、手机号/邮箱、密码、系统名称、租户模式。
  • 结果：平台账号、系统、默认租户、系统超级管理员成员、初始权限。
  • 落点：系统后台首次配置引导，不停在空仪表盘。

找回/重置密码

  • 身份校验、重置密码、踢出旧会话、返回登录。
  • 失败次数、验证码过期、账号锁定都要有明确反馈。

上下文

平台platformAccountId、平台角色、平台数据范围。
系统systemId、tenantId、systemMemberId、角色快照。
权限菜单、模块、动作、字段、数据范围、脱敏、后台入口。

登录后分流

  • 平台成员 -> 平台工作台。
  • 平台管理员 -> 可进平台后台。
  • 系统成员 -> 系统切换后进业务页。
  • 系统管理员 -> 业务页 + 系统后台入口。
  • 无 systemMemberId -> 无成员申请。

平台日常

平台侧能力闭环

平台仪表盘

  • 统计：系统数、租户数、授权应用、发布状态、待办、失败任务。
  • 列表：最近系统、最近 Flow、异常调用、授权到期。
  • 动作：创建系统、切换系统、查看系统状态、进入平台后台。

平台 Flow

  • 是独立大模块，不只是流程列表；详见“Flow 大模块深展开”。
  • 对内：审批、业务自动化、字段回写、待办消息、运行实例。
  • 对外：通过应用授权开放发起流程、查询实例、接收回调。
  • 边界：外部应用不能绕过应用 scope 直接调用内部流程。

应用/授权

  • 是应用授权大模块，承接内部应用、外部 OpenAPI、Flow 对外开放。
  • 字段：应用名、编码、类型、负责人、scope、SecretRef、回调、限流、状态。
  • 动作：申请、审批、授权、测试、发布、续期、撤销、转移、密钥轮换。
  • 边界：应用是接入来源和审计来源，不是业务数据父级。

平台工作

  • 详见“工作模块深展开”，固定四块：仪表盘、项目任务、普通任务、工作日志/日报。
  • 项目任务承载项目、任务组、任务、协作、验收、进度和业务对象关联。
  • 普通任务承载个人轻量任务，可后补项目、标签、业务对象和截止时间。
  • 工作日志/日报来自手写和自动草稿，提交前必须人工确认。

AI/待办/消息/个人

  • 待办：平台审批、授权申请、平台任务、模型额度申请。
  • 消息：右侧消息流，跳平台对象或系统切换。
  • Agent 分平台 Agent 和系统 Agent，详见“Agent 模块深展开”。
  • 个人信息：资料、安全、偏好、会话、后台入口权限。

平台后台

平台超级管理员治理全局能力，不配置系统业务字段，也不办理系统业务审批。

平台治理

全局配置和审计

平台信息/系统生命周期

  • 字段：平台名称、版本、系统数量、租户模式、授权状态、发布状态。
  • 动作：创建、停用、恢复、归档、调整配额、查看系统状态、发布版本。

组织账号/平台角色

  • 组织：部门树、成员、账号状态、MFA、登录方式。
  • 角色：平台后台入口、菜单、按钮、日志范围、模型授权范围。
  • 平台账号不等于系统成员。

配置管理

  • 统一身份源：OIDC/SAML、证书、JWKS、回调、域名白名单、属性映射、JIT、MFA。
  • AI 模型授权：本地模型、外部模型、额度、并发、外发限制、授权系统。
  • 容量和限流：用户数、系统数、字段数、导入导出并发、OpenAPI 调用。
  • 发布/缓存策略：requestId、traceId、错误码、幂等键、缓存失效。

平台日志

  • 登录日志：账号、身份源、IP、设备、地点、风险、结果。
  • 平台业务日志：系统生命周期、授权、模型、配额、配置发布。
  • 检索：logType、actor、traceId、auditLogId、时间、结果。

运行态业务

普通人能完成工作

业务仪表盘

  • 统计：模块数据、今日新增、待审批、逾期、异常、常用报表。
  • 组件：指标、图表、排行、进度、待办列表、数据列表。
  • 点击指标进入授权模块列表或筛选场景。

模块列表

  • 列表字段：收藏、序号、主字段、业务字段、状态、负责人、部门、时间、操作列。
  • 工具栏：关键字、保存视图、高级筛选、导入、导出、新建、批量动作。
  • 高级筛选：字段类型决定控件，文本模糊，数字范围，日期区间，字典多选，人员部门树。
  • 行点击打开右侧详情，复选框/按钮/输入控件不误触详情。

新建/编辑/详情

  • 表单：字段分组、默认值、必填、校验、联动、草稿、错误字段定位。
  • 详情：基础资料、附件、子表、关联数据、流程状态、历史、评论。
  • 保存：主数据、自定义字段、子表、附件、关联关系、历史一次闭环。

审批/待办/消息

  • 审批面板：当前节点、处理人、超时、动作、历史、流程图入口。
  • 待办：独立工作台，左类型右列表。
  • 消息：右侧消息流，整条点击跳关联对象，支持已读、归档、筛选。

文件/导入/导出/打印

  • 附件：真实上传、绑定记录、预览、下载权限、历史保留。
  • 导入：模板、上传、字段匹配、预检查、错误文件、确认、结果读回。
  • 导出：范围、字段、格式、脱敏、后台任务、结果文件、审计。
  • 打印：模板版本、字段快照、分页、签章区、打印历史。

工作/效率/系统 Agent

  • 工作：仪表盘、项目任务、普通任务、工作日志/日报，使用当前系统范围。
  • 效率：全局搜索、最近访问、收藏、快捷创建、扫码、拍照上传。
  • 系统 Agent：查询、统计、提取任务、工作日志/日报草稿、确认后写入。

详情工作区布局

不是普通弹窗

打开形态

  • 从右侧贴顶贴底打开，保留左侧列表、筛选、分页和当前行上下文。
  • 桌面端建议占视口 70%-82%；列表可窄化，详情主工作区不能压成窄卡片。
  • 入口来源：列表整行、待办、消息、全局搜索、最近访问、关联记录。
  • 状态：骨架屏、加载失败、无权限、记录不存在、归档只读、流程锁定。

顶部 sticky 头部

  • 模块标签、主标题/主字段、业务状态、审批状态、收藏、上一条/下一条、关闭。
  • 动作：编辑、转移、删除、打印、导出、发起审批、归档、更多。
  • 禁用原因：审批中、无权限、归档只读、状态不允许、字段停用、数据范围不足。
  • 重复详情入口不再放行内按钮；整行点击就是详情主动作。

上部主数据区

  • 主摘要字段：部门、负责人、状态、关键日期、最近业务事件、审批节点。
  • 车辆示例：车牌号、车辆状态、所属部门、负责人、年检到期、最近维保、审批状态。
  • 字段来源：详情显示字段、字段权限、角色权限、审批节点临时字段权限。
  • 脱敏：手机号、证件号、金额、密钥类字段在详情、导出、日志、AI 上下文分别受控。

上部状态联动

  • 审批中：编辑、删除、转移按规则禁用并显示短原因。
  • 审批通过：业务状态、流程状态和关键字段回写。
  • 审批拒绝/撤回：回到草稿或可编辑状态，顶部状态同步变化。

下部标签页

专属业务内容

详细资料

  • 按字段分组展示主数据、扩展字段、只读系统字段、隐藏字段不渲染。
  • 可配置分组：基础信息、业务信息、费用/预算/比例、风控信息、自定义分组。
  • 支持只读/编辑入口、字段错误定位、历史版本字段快照。
  • 不能用权限矩阵或通用说明表替代业务资料。

会话

  • 评论、回复、@成员、引用字段、附件、表情/快捷语、编辑/删除权限。
  • 关联对象：可把评论关联到当前模块、相关模块记录、任务、审批节点或附件。
  • 状态动作：置顶/取消置顶、设为有效/无效、标记已解决、折叠历史回复。
  • 通知：被 @ 人、负责人、协作人、审批人按消息模板接收提醒。

关联模块

  • 展示关联记录、引用字段、子表、反向关联、关联数量和目标模块状态。
  • 动作：新增关联、解除关联、设为主关联、设为有效/失效、置顶、排序、跳转详情。
  • 权限：目标模块可见、目标记录数据范围、目标字段脱敏都要重新计算。
  • 示例：车辆关联维保记录、驾驶员、合同、保险、费用、事故记录。

团队成员

  • 负责人、驾驶员、协作人、审批人、观察者、权限角色、加入时间。
  • 动作：转移负责人、添加协作人、移除成员、调整角色、发送提醒。
  • 来源：人员字段、组织架构、流程审批人、手动团队维护。
  • 不能复用系统角色权限表，要展示当前记录团队关系。

附件/打印记录

  • 附件：文件名、类型、大小、上传人、上传时间、来源字段、预览、下载权限。
  • 动作：上传、替换、删除、下载、预览、设为有效/失效、关联会话或审批节点。
  • 打印记录：模板版本、打印人、时间、字段快照、页数、结果、失败原因。
  • 历史打印记录保留当时模板和字段版本。

操作记录

  • 时间线或日志表：操作人、动作、对象、字段前后值、审批结果、来源入口。
  • 记录范围：新建、编辑、删除、转移、附件、评论、关联、打印、导入导出、AI 写入。
  • 审计字段：requestId、traceId、auditLogId、权限快照、脱敏结果、失败原因。
  • 支持按动作、人员、时间、字段、审批节点筛选。

右侧审批面板

有审批才显示

显示条件与位置

  • 当前记录存在流程实例、审批历史或可发起审批时显示；无审批时隐藏或显示轻量入口。
  • 固定在详情右侧，宽度 280-340px，与详情标签页并列，不挤进下部 tab。
  • 待办进入详情时直接定位审批面板；消息进入时定位对应审批节点或历史。

当前节点卡

  • 字段：审批状态、节点名称、节点说明、处理人/候选人、发起人、到达时间、超时规则。
  • 权限提示：当前登录人是不是处理人，非处理人隐藏或禁用审批按钮并说明原因。
  • 节点字段权限：当前节点哪些字段可见、可编辑、必填、隐藏。

审批动作区

  • 动作：同意、拒绝、转办、加签、退回、撤回、恢复、评论、上传附件、更多。
  • 动作配置：二次确认、必填意见、必填附件、必填字段、候选人选择、退回节点选择。
  • 提交反馈：同步结果、后端任务、错误字段定位、重复提交幂等提示。

审批字段改动

  • 节点可配置要改动的业务字段：状态、负责人、金额、日期、分类、风险等级、备注等。
  • 办理时显示字段改动区：旧值、新值、必填、校验、联动、是否写入历史。
  • 字段可见/可改来自角色字段权限 + 审批节点覆盖；节点权限可以临时开放或收紧。
  • 提交前预览影响：业务状态、待办、消息、关联记录、导出字段、AI 上下文。

审批历史

  • 时间线：发起、流转、同意、拒绝、退回、撤回、转办、加签、超时、终止。
  • 每条历史展示处理人、动作、意见、附件、字段前后值、节点快照、处理时间。
  • 入口：查看流程图、查看历史审批流程、定位业务操作记录、复制 traceId。
  • 禁止用简单 stepper 替代当前节点卡和审批历史。

审批完成读回

  • 写回：业务状态、流程状态、审批字段改动、操作记录、审批历史、待办、消息、日志。
  • 终态：重复审批按钮禁用，待办从待处理移除，消息显示已处理或终态。
  • 失败补偿：字段校验失败、处理人不匹配、流程版本失效、节点已处理、权限变化。

Flow 对象

先分清定义和运行

Flow 列表

  • 列表字段：名称、编码、所属系统、绑定模块、触发方式、版本、状态、负责人、最近运行、错误数。
  • 高级筛选：系统、模块、触发事件、状态、版本、负责人、更新时间、运行结果、关键字。
  • 基础动作：新建、复制、编辑、模拟、发布、禁用、导入、导出、转移负责人、影响分析。
  • 列表不是终点；行点击进入流程定义、版本、画布、运行实例和授权关系。

内部流程

  • 用途：审批流、状态流转、字段回写、通知抄送、数据创建/更新、业务自动化。
  • 绑定：系统、租户、模块、场景、动作、字段、角色、数据范围。
  • 触发：手动发起、新建记录、编辑记录、状态变化、导入完成、定时、待办、消息。
  • 边界：内部流程使用当前系统成员和角色权限，不接受外部 app 直接绕权执行。

画布与节点

  • 画布：左节点库、中间可缩放画布、连线箭头、条件分支标签、右属性面板。
  • 节点：开始、审批、条件、并行、抄送、填写、字段更新、创建数据、更新数据、通知、外部 API/Webhook、等待/定时、子流程、AI 辅助、结束。
  • 连线：普通线、条件线、异常线、超时线、退回线，必须能标明条件和目标节点。
  • 视图：版本快照、只读历史、发布版本、草稿版本、模拟路径高亮。

节点属性

  • 审批节点：或签、会签、顺序、处理人来源、候选人、抄送人、超时、代理、转办、加签、退回。
  • 字段权限：当前节点字段可见、可编辑、必填、隐藏、脱敏，允许覆盖角色字段权限但要记录原因。
  • 字段改动：状态、负责人、金额、日期、分类、风险等级、备注等字段的旧值、新值和校验。
  • 异常：无审批人、字段冲突、外部 API 失败、节点超时、版本失效时的补偿策略。

运行和对外

内部使用与外部授权分开

发布检查/模拟

  • 检查：无开始/结束、断线、空审批人、字段权限冲突、死路径、未配置消息模板、外部 API 未测试。
  • 模拟：选择发起人、角色、模块记录、字段值、租户，预览命中路径、当前节点和字段权限。
  • 发布：生成流程版本、节点快照、字段权限快照、消息模板引用、授权影响范围。
  • 发布失败必须显示阻塞项、定位节点、traceId 和下一步动作。

内部运行实例

  • 实例字段：instanceId、flowVersion、recordId、发起人、当前节点、状态、开始时间、结束时间。
  • 运行读回：详情审批面板、当前处理人待办、发起人消息、业务状态回写、操作记录。
  • 动作：提交、同意、拒绝、转办、加签、退回、撤回、终止、恢复、重试。
  • 幂等：同一 task/action/requestId 只能处理一次，终态节点禁止重复提交。

应用授权对外

  • 外部应用只能通过应用 scope 发起流程、查询实例、查询历史、接收回调，不能直接访问内部画布编辑。
  • 授权项：可用 Flow、可发起模块、可写字段、可读字段、可查询状态、可接收回调事件、数据范围。
  • 提交参数：appKey、签名、timestamp、nonce、idempotencyKey、flowCode、recordPayload、callbackUrl。
  • 回调：实例创建、节点到达、审批完成、拒绝、异常、超时，必须带 traceId 和签名。

Flow 日志/监控

  • 日志：实例日志、节点日志、审批动作日志、字段改动日志、消息投递日志、外部调用日志。
  • 监控：运行中、异常、超时、重试中、补偿中、终态成功、终态拒绝、终止。
  • 字段：traceId、requestId、auditLogId、nodeId、actor、before/after、errorCode、retryCount。
  • 入口：从 Flow 列表、详情审批面板、待办、消息、日志管理都能定位同一实例。

应用列表

  • 筛选：系统、类型、状态、负责人、授权范围、到期、最近调用、风险、关键字。
  • 动作：新建、复制、编辑、启用/停用、申请授权、发布测试、导入导出、转移负责人。

应用详情

  • 基础字段：名称、编码、描述、负责人、联系人、所属系统、租户范围、创建人、更新时间。
  • 安全字段：appKey、OpenApiSecretRef、SecretRef 版本、密钥到期、轮换状态、最近使用。

授权范围

  • 系统/租户：允许访问哪些系统和租户，单租户隐藏租户选择，多租户必须带 tenantId。
  • 模块/动作：查询、新建、编辑、删除、上传、导入、导出、发起流程、查询流程、接收回调。
  • 字段/数据：可读字段、可写字段、可导出字段、脱敏规则、dataScopeExpression、默认过滤条件。
  • 审批：申请、审核、变更、续期、撤销、转移、过期、禁用都要写入授权历史。

授权生命周期

  • 草稿配置 -> 发布检查 -> 授权审批 -> 测试调用 -> 生效 -> 续期/变更 -> 停用/撤销。
  • 变更检查：新增写权限、字段外发、Flow 发起、导出权限、回调变更都要高风险提示。
  • 密钥轮换：生成新版本、双写验证、切换生效、停用旧版本、失败回滚、审计。
  • 授权撤销后，接口返回明确错误，后台仍保留历史日志和授权快照。

对外能力

从能力到日志闭环

OpenAPI

  • 能力：创建记录、编辑记录、查询列表/详情、上传附件、导入、导出、发起流程、查询流程。
  • 鉴权：appKey、SecretRef、签名、timestamp、nonce、idempotencyKey、请求过期校验。
  • 响应：业务结果、错误码、traceId、requestId、字段裁剪结果、异步任务 id。
  • 文档：接口版本、字段 schema、示例、错误码、限流说明、回调签名规则。

Flow 对外

  • 外部应用可发起授权 Flow，提交授权字段，不能修改流程定义和内部节点属性。
  • 可查询：实例状态、当前节点名称、历史动作、终态结果、错误状态。
  • 可回调：审批通过、审批拒绝、节点异常、超时、补偿失败、流程终止。
  • 失败状态：Flow 未授权、字段无权、签名错误、幂等冲突、流程版本停用。

调用安全

  • 安全策略：IP 白名单、域名白名单、限流、并发、配额、请求体大小、附件类型。
  • 权限拒绝：只读 scope 写入、字段无权、数据范围外、导出字段脱敏、Flow 未授权。
  • 密钥错误：SecretRef 过期、签名错误、timestamp 过期、nonce 重放、版本不匹配。
  • 错误返回不能只说失败，要给 errorCode、traceId、处理建议和是否可重试。

调用日志

  • 字段：appId、appKeyMasked、endpoint、method、status、duration、requestId、traceId、auditLogId。
  • 内容：入参摘要、出参摘要、字段裁剪、脱敏结果、错误码、重试次数、结果文件。
  • 筛选：应用、接口、状态、错误码、时间、traceId、业务对象、Flow 实例。
  • 联动：日志可跳应用详情、授权快照、业务记录、Flow 实例和系统业务日志。

工作仪表盘

Agent 边界

先定能不能做

平台 Agent

  • 禁止：无系统成员上下文时读取或修改系统模块记录、审批、任务和日志。

系统 Agent

  • 入口：系统业务页右侧助手、系统后台 Agent 策略、工作日志草稿、详情页辅助。
  • 范围：当前 systemId、tenantId、systemMemberId、角色、字段权限、数据范围。
  • 能力：查询统计、字段解释、任务提取、日报草稿、流程建议、确认后写入业务数据。

Agent 策略配置

  • 策略字段：模型来源、模型版本、AgentPolicyScope、策略版本、启用状态、负责人。
  • 范围：moduleScope、fieldScope、actionScope、dataScopeExpression、外发限制、脱敏策略。
  • 确认策略：查询免确认、草稿需确认、写入强确认、导出二次确认、高风险禁止。
  • 发布检查：模型授权、字段可访问、工具权限、外发脱敏、提示词版本、普通成员预览。

工具与提示词

  • 工具：查询列表、读详情、统计、创建任务、生成日报草稿、发起流程、导出申请。
  • 提示词：平台提示词、系统提示词、模块提示词、字段解释、禁用词、输出模板。
  • 版本：promptVersion、toolVersion、modelAuthVersion、policyVersion，运行日志要保存快照。
  • 失败：模型不可用、工具超时、字段隐藏、scope 不足、上下文过长时走降级策略。

运行闭环

每次回答都要可追踪

对话运行

  • 输入：用户问题、入口来源、当前对象、当前筛选、当前角色、系统/租户上下文。
  • 识别：意图、目标模块、目标字段、目标对象、是否需要工具、是否涉及写入。
  • 裁剪：按字段权限、数据范围、脱敏、外发限制裁掉不可访问数据。
  • 输出：结果摘要、依据字段、数据来源、不可见原因、下一步建议。

写入确认

  • 确认页展示草稿变更：对象、字段、旧值、新值、原因、置信度、风险提示、关联影响。
  • 动作：确认执行、修改草稿、取消、只保存为建议、转人工、生成待办。
  • 字段：可见字段、可写字段、必填字段、隐藏字段、脱敏字段必须分开呈现。
  • 审批/Flow：若写入会触发流程，要预览流程、当前节点、审批字段改动和消息待办影响。

执行结果

  • 结果：创建/更新记录、创建任务、生成日报草稿、发起流程、创建导出任务、发送消息。
  • 读回：返回记录详情、任务详情、日报草稿、Flow 实例、后台任务、消息/待办状态。
  • 状态：执行中、成功、失败、部分成功、需人工处理、已补偿。
  • 用户看到的不只是 toast，要能跳转到结果对象或日志。

失败和审计

  • 失败：低置信度、无权限、字段隐藏、数据范围外、模型失败、工具失败、重复提交、流程冲突。
  • 补偿：重试、保存草稿、转人工、创建待办、补偿处理、提示需要管理员配置。
  • 审计字段：agentSessionId、model、promptVersion、toolCall、policyVersion、traceId、auditLogId。
  • 日志：平台 Agent 写平台日志，系统 Agent 写系统业务日志，二者不能混用。

权限如何决定显示

前端显示和后端拒绝要一致

权限配置入口

  • 入口：系统后台 -> 角色权限 -> 菜单权限、模块权限、动作权限、列表功能权限、字段权限、数据范围。
  • 列表功能权限：advancedFilter、saveView、columnSetting、import、export、print、batchAction、refresh、pagination。
  • 按钮权限：create、edit、delete、transfer、archive、submitFlow、approve、reject、print、export、customAction。
  • 字段权限：visible、editable、searchable、filterable、exportable、importable、openApiReadable、agentReadable。

有效权限计算

  • 输入：SystemSwitchContext、TenantSwitchContext、systemMemberId、roleIds、tenantId、moduleId、recordId。
  • 输出：EffectivePermissionSnapshot，包含菜单、模块、动作、字段、数据范围、后台入口、拒绝原因。
  • 合并：多角色权限合并后仍要受租户、成员状态、模块发布状态、字段停用、数据范围限制。
  • 缓存：发布、角色变更、成员变更、租户切换、字段发布后必须刷新权限缓存。

按钮显示/禁用判定

  • 隐藏：菜单无权、模块无权、actionCode 无权、功能未配置、字段无权导致动作不可成立。
  • 禁用：记录归档、流程锁定、状态不允许、未选中数据、选中数量不符、审批人不匹配。
  • 显示但只读：可查看无编辑权、可导出无全部字段权、可发起但缺必填字段时给错误定位。
  • 每个禁用按钮都要有 disabledReason，不能只变灰。

后端拒绝

  • 前端隐藏只是体验，后端必须按 permissionCode、fieldCode、dataScopeExpression 再判断。
  • 拒绝场景：未授权 API、字段写入无权、导出字段无权、OpenAPI scope 不足、Agent 越权。
  • 返回：HTTP 状态、errorCode、message、traceId、deniedPermission、deniedField。
  • 拒绝也要写权限拒绝日志，方便审计和排查。

外部接入与 AI

外部接入和 AI 都有平台入口与自建系统入口；导入导出归模块动作，项目级运行维护不作为产品业务流程。

双入口边界

平台归平台，系统归系统

平台对外接入

  • 入口：平台工作台应用/授权，平台后台应用配置。
  • 能力：平台授权申请、平台 Flow、平台任务、平台消息、平台日志。
  • 边界：不能直接读写自建系统业务模块记录。
  • 需要业务数据时，引导进入对应系统，由系统对外应用授权。

自建系统对外应用

  • 入口：系统后台 -> 对外应用/OpenAPI。
  • 配置：OpenApiSecretRef、模块 scope、动作 scope、字段 scope、数据范围、Flow scope。
  • 调用：创建、编辑、查询、上传、发起流程、查询流程状态。
  • 反例：wrong secret、read-only scope、字段无权、数据越权、限流、签名过期。

平台 Agent

  • 入口：平台工作台顶部 AI，平台后台模型授权和策略配置。
  • 允许：平台授权、日志、任务消息、模型额度、系统切换指导。
  • 禁止：无系统成员上下文直接读写系统业务记录。
  • 确认页只生成平台任务、平台消息、平台日志。

系统 Agent

  • 入口：系统业务页 Agent，系统后台 AI Agent 配置。
  • 范围：当前 system/member/role/dataScope。
  • 能力：查询统计、任务提取、工作日志/日报草稿、确认后写入、发起流程。
  • 约束：字段权限、数据范围、脱敏、低置信度拦截、二次确认。

导入导出归属

  • 导入导出不是外部接入模块，也不是平台功能。
  • 它属于系统后台模块动作配置：启用、字段范围、权限、模板、结果文件。
  • 发布后在系统业务页模块列表工具栏出现。
  • 任务进度、失败文件、结果读回归模块运行态和系统日志。

自建系统发布

  • 自建系统建成后是发布或不发布配置，不是 examine2 项目级运行维护。
  • 发布对象：模块、字段、页面动作、流程、字典、工作配置、Agent 策略、对外应用。
  • 不发布：草稿保留，不进入运行态。
  • 已发布：运行态、OpenAPI、AI 和导出只读发布版本。

横向闭环规则

每个业务流程最终都要落到权限、状态、日志、发布版本、读回和验收证据上。

防跑偏检查

开发任务都要能映射回来

权限与数据范围

  • 前端隐藏只是体验，后端必须拒绝未授权 API。
  • 字段权限影响列表、表单、详情、导出、OpenAPI、AI 和日志快照。
  • 按钮和列表功能必须能说明 actionCode、permissionCode、显示/隐藏/禁用原因。
  • 数据范围包括本人、本部门、下级、指定成员、按字段规则。

状态与反馈

  • 加载、空、错误、无权限、禁用、后台任务中、成功、失败。
  • 保存、发布、审批、AI 写入、导入导出必须有结果承接。

发布与版本

  • 模块、字段、列表、筛选、按钮动作、打印、Flow、字典、工作配置、Agent 策略都要有版本。
  • 发布前检查阻塞项必须可读，不用泛化 toast 代替。
  • 运行态只读已发布版本，历史记录保留当时配置、字段、按钮和权限快照。

验收映射

  • 任一需求都要能映射到入口、角色、页面、字段、按钮、列表功能、权限、日志、状态和读回。
  • 每个模块都要能回答：对象是谁、默认字段是什么、按钮从哪里来、权限怎么裁、日志写什么。
  • 用户举例只代表一类规则；同类对象必须扫描补齐，不能只补被点名的一个对象。
  • 页面存在、API 200、构建通过只能算证据，不能单独算项目完成。
  • 用户验收未签字前，只能说工程证据支持，不能说最终目标完成。

功能归属与使用矩阵

这里不是新增功能域，而是说明每个动作归到哪里、什么时候用、谁能用、业务逻辑和结果怎么读回。

归类原则

先归属，再讲细节

四个阅读维度

  • 功能结构：先判断属于平台工作台、平台后台、系统业务页、系统后台中的哪一个。
  • 使用时机：说明用户在哪条路径、什么状态下触发。
  • 角色权限：说明谁可见、谁可点、谁可写、谁可导出、谁可审批。
  • 业务逻辑：说明改变什么对象、产生什么状态、怎么读回、写什么日志。

不能单独列成模块

  • 导入、导出、打印、批量编辑、转移、删除属于模块页面动作。
  • 附件属于字段、评论、审批、导入导出结果或文件对象的组成部分。
  • 待办、消息、日志是结果承接和追踪入口，不替代原业务对象。
  • 发布/不发布是自建系统配置进入运行态的状态，不是项目运行维护流程。

双入口能力

  • OpenAPI：平台入口只处理平台对象；系统入口授权当前系统的模块、字段、动作和流程。
  • AI：平台 Agent 只处理平台授权、日志、任务、模型额度；系统 Agent 只处理当前系统业务。
  • 消息：平台消息不直接打开系统业务详情；系统消息必须在系统成员上下文中跳转。

功能归属矩阵

动作挂回所属功能

模块运行态

  • 列表、筛选、列设置、批量选择属于模块列表。
  • 新建、编辑、详情、评论、附件属于模块记录。
  • 导入、导出、打印属于模块动作，由系统后台配置并发布。

流程协作

  • 审批属于流程运行，不是详情页独立功能；详情页只是承接审批面板。
  • 待办属于当前成员要处理的任务入口，结果回写流程实例和业务记录。
  • 消息属于通知入口，跳转目标必须回到原业务对象。

配置发布

  • 字段、列表、页面动作、流程、字典、工作配置、Agent 策略都先是草稿。
  • 发布后才进入运行态；不发布则只留在后台草稿。
  • 运行态、OpenAPI、AI、导出只能读取已发布版本。

归属：入口与四套壳

先保证用户进对地方

账号安全场景

  • 无 token、token 过期、刷新失败、强制下线都只能回登录，并清平台/系统/租户上下文。
  • 账号密码错误、账号停用、失败锁定、MFA 错误、验证码过期、SSO 回调失败都要有用户可读原因和登录日志。
  • 注册并创建系统要处理账号已存在、系统编码重复、初始化模板失败、成员绑定失败和补偿任务。
  • 成功后创建人成为系统超级管理员，并进入系统后台首次配置引导。

四套壳边界

  • 平台工作台：Flow、应用、工作、AI、系统切换、创建系统、待办、消息、个人信息。
  • 平台后台：平台信息、组织账号、平台角色、配置管理、日志；不放系统业务字段和审批办理。
  • 系统业务页：系统、租户、模块组、左侧模块、列表/表单/详情/工作/待办/消息/Agent。
  • 系统后台：系统信息、组织、统一认证、角色、模块、工作配置、Flow、字典、仪表盘、数据源、对外应用、日志。

上下文反例

  • 平台账号不能直接打开系统业务数据，必须先有 SystemSwitchContext。
  • 单租户隐藏租户切换，多租户切换必须刷新模块、列表、待办、消息、字段权限和数据范围。
  • 无 systemMemberId 只能生成 NoMemberAccessRequest，审核前不能自动授权。
  • 直连无权限后台 URL 显示无权限页，不闪现真实页面。

归属：模块运行态

列表、表单、详情的日常使用

列表场景

  • 加载、空数据、筛选无结果、无权限、模块未发布、接口失败必须分开显示。
  • 搜索、高级筛选、排序、分页、列设置、保存视图、批量选择和清除选择都要有可见状态。
  • 业务数据行点击打开详情；复选框、按钮、链接、输入框不能误触发行详情。
  • 隐藏字段不能出现在列表、导出、OpenAPI、AI 返回和日志明文中。

字段与表单

  • 文本、数字、金额、日期、选项、人员、部门、附件、关联、子表、公式、自动编号、密钥、AI 填充都要有专属配置。
  • 必填、唯一、正则、范围、条件必填、条件显隐、默认值、只读、脱敏、字典停用历史都要覆盖。
  • 草稿支持自动保存、手动保存、恢复、丢弃、过期；校验失败定位到错误字段并展开分组。
  • 重复保存用 idempotencyKey 防重复，成功后读回详情或刷新列表。

详情与审批

  • 详情包含主标题、状态、编号、收藏、上一条/下一条、编辑、删除、打印和更多动作。
  • 标签页覆盖详细资料、团队成员、关联数据、子表、附件、打印记录、审批历史、操作记录。
  • 审批支持发起、同意、拒绝、转办、加签、退回、撤回、终止、评论、附件和节点字段权限。
  • 审批终态后重复操作返回冲突并禁用按钮；业务状态、流程状态、待办、消息和操作记录同步读回。

归属：模块动作

文件、导入导出、打印挂在模块下

导入

  • 模板按发布版本、字段权限、字典项和必填规则生成。
  • 上传校验格式、大小、空文件、重复上传和安全检查。
  • 字段匹配、预检查、错误文件、确认导入、部分成功、失败回滚和不可回滚原因都要可见。
  • 错误文件记录行号、字段、原因和修复建议；任务结果能从消息、待办、日志追踪。

导出与文件

  • 导出范围包括全部、筛选结果、选中记录、当前页；字段按权限和脱敏裁剪。
  • 大导出异步任务，支持取消、重试、下载过期和审计日志。
  • 文件区分字段附件、评论附件、审批附件、导入文件、导出结果文件。
  • 预览、下载、链接过期、文件丢失、权限不足、失败重试都要有状态。

打印

  • 模板覆盖字段、关联字段、子表、页眉页脚、签章区和套打偏移。
  • 打印记录保存模板版本、字段快照、打印人、时间、结果和失败原因。
  • 浏览器打印、print-ready HTML、PDF 下载边界要明确。
  • 模板停用、字段缺失、权限不足、渲染失败都不能只弹泛化成功。

归属：流程、消息、开放能力

自动化和外部调用各有入口

Flow 和待办消息

  • 新建 Flow 空画布不能注入演示节点；无开始/结束、断线、死路、审批人空、字段权限冲突都阻塞发布。
  • 节点库覆盖审批、条件、并行、抄送、填写、通知、字段更新、外部 API、等待、子流程、AI。
  • 待办有待处理、已处理、已转办、已过期、已撤回、已归档状态。
  • 消息模板包含 templateCode、变量、渠道、跳转目标、去重、免打扰、失败重试和 message_delivery_log。

OpenAPI 与密钥

  • 外部应用配置 appKey 掩码、SecretRef、版本、轮换状态、scope、白名单、限流和回调。
  • 调用校验签名、时间戳、防重放、幂等键、模块/动作/字段/数据范围。
  • wrong secret、read-only scope、字段无权限、数据越权、缺幂等键、限流和回调失败都有日志。
  • 密钥轮换包含新版本、双写验证、切换生效、旧版本停用、失败回滚和审计。

AI Agent

  • 平台 Agent 只能查平台授权、日志、任务、模型额度、系统状态和切换指导。
  • 系统 Agent 只在当前 system/member/role/dataScope 内查询、统计、提取任务、生成日报草稿或确认后写入。
  • 批量修改、导出、发起流程、AI 写入都必须二次确认。
  • 低置信度、模型超时、工具失败、权限不足、外发限制和脱敏拦截都写审计。

单独维度：技术契约和业务模板

用于说明实现边界，不作为页面功能

自建系统发布

  • 发布对象：模块、字段、列表、筛选、页面动作、导入导出动作、打印、流程、字典、工作配置。
  • 草稿只在后台可见；不发布则保留草稿，不影响当前运行态。
  • 发布检查失败要显示阻塞项、影响范围、修复入口和 traceId。
  • 已发布版本被运行态、OpenAPI、AI、导出使用，并记录版本、发布人、时间和审计。

技术契约

  • API 统一 URL、方法、分页、排序、筛选、错误码、requestId、traceId 和时间格式。
  • 错误码按账号、系统、模块、字段、权限、流程、文件、OpenAPI、AI、配置发布分域。
  • 保存、审批、OpenAPI 写入、导入确认、导出创建要防重复；登录、注册、上传、导入导出和高频查询要限流。
  • 性能覆盖大表格分页、筛选索引、仪表盘缓存、大任务异步、文件超时和失败恢复。

典型业务模板

  • CRM：客户、联系人、跟进、合同、订单、回款、负责人/部门权限。
  • OA：请假、报销、采购、审批、附件、预算、打印、归档。
  • 项目：项目任务、普通任务、日报、风险、验收、关联业务对象。
  • 资产/工单/巡检/轻量 ERP/MES：资产、维修、派单、扫码拍照、库存台账、生产工单、质检记录。

移动和文档

  • 移动端支持扫码定位对象、拍照上传、移动表单草稿、移动审批和失败重试。
  • 小屏表格需要卡片替代展示，关键操作不能依赖悬停。
  • 文档覆盖配置说明、管理员手册、普通用户手册、OpenAPI、FAQ、排错、配置发布、字段/流程/权限配置。
