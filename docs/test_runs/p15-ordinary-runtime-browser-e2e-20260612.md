## 浏览器剧本

2. 普通账号左侧导航只显示 `切换系统`、`业务运行台`、`流程工作台`，未出现平台管理、系统设置、建模配置、字段设计、发布和权限配置入口。
3. 业务运行台出现已授权模块入口，下一步提示为“点击模块进入列表并新增记录”，不再误提示“当前没有可用业务模块”。
4. 点击模块入口后进入运行模块页，字段展示为 `车型`、`颜色`、`车牌号`、`登记日期`、`备注`。

6. 已提交记录显示为 `已提交`，不再暴露原始状态值 `SUBMITTED`。
7. 清理早期自动化污染记录后，列表只保留有效记录 `Model-Y` 和 `Tesla 3`，分页显示 `共 2 条，第 1 / 1 页`。

## 修复项

- 后端运行台菜单按真实授权菜单过滤，不再要求普通成员具备管理型 `SYSTEM_MEMBER` 操作入口。
- 后端记录详情、编辑、删除、提交的数据范围校验改为按 `MODULE + moduleId` 匹配角色授权。
- 后端运行台 schema 输出时用当前字段定义覆盖发布快照中的字段标签，避免历史快照或编码污染导致普通用户看到问号字段。
- 后端删除记录历史补齐 `after_snapshot_json`，避免删除时因 NOT NULL 字段写入空值而返回 500。
- 前端运行模块页不再依赖管理端模块列表，普通成员无需 `MODULE_VIEW` 也能通过运行台模块入口打开业务表单。
- 前端运行台下一步提示改为同时参考实际授权运行菜单，状态标签补齐 `SUBMITTED/APPROVED/REJECTED/WITHDRAWN/DELETED` 等中文显示。
