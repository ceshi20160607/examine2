## 3. 字段配置（核心 · 右侧抽屉）

**入口：** 建模 → 字段配置 Tab → 添加字段 / 编辑行 → **右侧抽屉**（占视口约 40%–480px，Design 定宽）

### 3.1 抽屉分区

```
┌─ 字段配置 ─────────────────────────────── [×] ┐
│ 【基础】 名称、编码、类型、排序、说明          │
│ 【展示】 表单/详情/列表 显隐、占位、宽度占比    │
│ 【数据】 必填、只读、默认值、唯一、字典/关联    │
│ 【列表】 可搜索、可筛选、列宽、固定列          │
│ 【高级】 公式/汇总/状态 等（按类型展开）       │
│                    [停用字段] [取消] [保存]   │
└──────────────────────────────────────────────┘
```

### 3.2 基础（所有类型共有）

| 配置项 | 控件 | 必填 | 说明 | 运行态影响 |
|--------|------|:----:|------|------------|
| 显示名称 | 输入 | ✅ | 中文，如「车牌号」 | 表头/表单 label |
| 字段编码 | 输入 | ✅ | 英文 snake，如 `plate_no` | API/导入/映射唯一键 |
| 字段类型 | 下拉 | ✅ | 见 §3.4 | 决定后续表单项 |
| 排序 | 数字 | | 默认 100 | 表单/列表顺序 |
| 字段说明 | 多行 | | 管理员备注 | 可选展示给配置者 |

### 3.3 展示与布局

| 配置项 | 控件 | 默认 | 说明 |
|--------|------|------|------|
| 表单中显示 | 开关 | 开 | 关=隐藏字段（仍可通过权限/流程写入） |
| 详情中显示 | 开关 | 开 | 详情 Tab「详细资料」 |
| 列表中显示 | 开关 | 按字段 | 关=默认不在列表列 |
| 表单占位提示 | 输入 | | placeholder |
| 表单宽度占比 | 单选 | 半行(50%) / 整行(100%) | 两列表单网格 |
| 详情宽度占比 | 单选 | 半行 / 整行 | 详情两列网格 |
| 列表默认列宽 | 数字/下拉 | 自动 / 120px | 列表配置可覆盖 |

### 3.4 字段类型（下拉项 · MVP 必含）

| 类型值 | 显示名 | 类型专属配置（§3.5） |
|--------|--------|----------------------|
| `text` | 单行文本 | 最大长度 |
| `textarea` | 多行文本 | 行数 |
| `number` | 数字 | 小数位、最小/最大 |
| `money` | 金额 | 币种、小数位 |
| `date` | 日期 | 格式 |
| `datetime` | 日期时间 | 格式 |
| `select` | 单选下拉 | **数据来源 §3.6** |
| `multiselect` | 多选 | 数据来源 |
| `switch` | 开关 | 开/关文案 |
| `user` | 人员 | 单选/多选 |
| `dept` | 部门 | 单选/多选 |
| `file` | 附件 | 数量、大小、类型 |
| `image` | 图片 | 同附件 |
| `auto_number` | 自动编号 | 前缀、规则、序号 scope |
| `relation` | 关联数据 | **关联模块 §3.7** |
| `subtable` | 子表 | 子模块/字段列 |
| `formula` | 公式 | 表达式（增强可灰显） |
| `status` | 状态 | 状态机/字典 |

### 3.5 数据规则（所有类型）

| 配置项 | 控件 | 说明 |
|--------|------|------|
| 必填 | 开关 | 表单校验 |
| 只读 | 开关 | 运行态不可编辑（含编辑页） |
| 默认值 | 按类型 | 新建时预填 |
| **唯一** | 开关 + 范围 | 模块内唯一；可组合多字段唯一（增强） |
| 唯一提示文案 | 输入 | 重复时 toast，如「车牌号已存在」 |

### 3.6 下拉/单选 · 数据来源（`select` / `status`）

| 来源类型 | 控件 | 必填子项 | 映射说明 |
|----------|------|----------|----------|
| 静态选项 | 选项表格 | 选项名、选项值、排序、启用 | 存 value，显示 label |
| **数据字典** | 下拉 | 选择字典类型，如「车辆状态」 | 运行态选项来自 `admin-dict` |
| 模块数据 | 下拉 | **源模块** + **显示字段** + **值字段** | 例：驾驶员模块.姓名 → 存 recordId |
| 公式/接口 | 占位 | 增强期 | |

**车系统示例 · 车辆状态：**

- 类型：`select`
- 数据来源：字典 → `车辆状态`
- 必填：是
- 列表显示：是
- 可筛选：是

### 3.7 关联字段 · 映射到模块下字段

| 配置项 | 控件 | 示例（驾驶员） |
|--------|------|----------------|
| 关联目标模块 | 下拉 | 本系统 → **驾驶员** 模块 |
| 选择方式 | 单选 / 多选 | 单选 |
| 显示字段 | 下拉（目标模块字段） | 姓名 |
| 存储字段 | 固定 | 关联 recordId（用户不可见） |
| 列表展示 | 开关 | 列表显示「张伟」而非 ID |
| 筛选支持 | 开关 | 高级筛选可按驾驶员筛 |

**保存规则：** 库内 storeId；界面 show 显示名称；历史数据保留显示快照（字典/关联改名不影响历史可读）。

### 3.8 列表相关（字段级）

| 配置项 | 控件 | 说明 |
|--------|------|------|
| 可搜索 | 开关 | 进入快捷搜索范围 |
| 可高级筛选 | 开关 | 进入高级筛选抽屉 |
| 可排序 | 开关 | 表头排序箭头 |
| 默认排序方向 | 升/降/无 | 模块默认排序字段 |
| 列表对齐 | 左/中/右 | 金额/日期可右对齐 |

## 4. 列表配置 Tab

**布局：** 可编辑表格，列=运行态列表列定义。

| 列（配置表头） | 说明 |
|----------------|------|
| 字段 | 来自已发布字段；下拉添加 |
| 显示名 | 可覆盖字段显示名 |
| 列宽 | px 或 自动 |
| 最小宽度 | px |
| 固定 | 无 / 左 / 右 |
| 默认排序 | 无 / 升序 / 降序 |
| 允许用户隐藏 | 开关 |
| 默认显示 | 开关 |
| 操作 | 上移/下移/移除 |

**车系统默认列顺序：** 车牌号、品牌型号、状态、部门、驾驶员、购置日期、年检到期、最近维保

**与用户个人「列设置」关系：** 此处=系统默认；运行态用户改动存个人偏好，不反写建模。

## 10. 建模原型最低展示要求（admin-modeling）

Open Design / 原型必须**至少**演示：

1. **字段配置 Tab**：字段列表 5 行 + **打开「车辆状态」字段抽屉**，含：类型=下拉、字典来源=车辆状态、必填、列表/筛选开关  
2. **列表配置 Tab**：列顺序表 + 固定列示例  
3. **场景配置 Tab**：「在用车辆」「待年检」两行 + 条件摘要  
4. **页面动作 Tab**：导出/导入/转移等 checkbox  
5. 抽屉内 **表单宽度占比**、**唯一** 开关可见（不必全类型各做一页）

|----|------|------|
| M-ADD-MEMBER | 搜索用户、部门、角色 | 取消、确认添加 |
| M-CREATE-SYSTEM | 系统名、编码 | 取消、创建 |
| M-COLUMN-SETTINGS | 列显隐、顺序、宽、固定 | 重置、保存 |
