## 审阅清单

- [ ] **四套壳分离**：平台工作台、平台后台、系统业务页、系统后台导航完全分开。
- [ ] **平台工作台**：顶部仪表盘、Flow、应用；右侧待办、消息、个人信息。
- [ ] **平台后台**：左侧平台信息、组织架构、角色管理、仪表盘管理、配置管理、日志管理。
- [ ] **系统业务页顶部**：参考 CRM 骨架，顶部展示系统/应用入口、仪表盘、模块分组、待办、消息、个人信息和工具图标，当前分组高亮。
- [ ] **业务分组布局**：点击模块分组后，左侧显示该分组下模块，右侧显示当前模块数据列表。
- [ ] **详情打开方式**：详情从右侧打开并保留左侧列表上下文，不做居中普通弹窗。
- [ ] **详情骨架**：详情顶部有模块标签、主标题、关键摘要、转移/编辑/删除/打印/更多按钮。
- [ ] **详情标签页**：详情下部有详细资料、团队成员、金额/比例设置、附件、打印记录、操作记录。
- [ ] **详情审批面板**：详情右侧有审批流程信息、当前节点、处理人、历史流程入口和审批按钮。
- [ ] **系统后台**：左侧系统信息、组织架构、角色管理、模块管理、流程管理、字典管理、仪表盘管理、数据源、对外应用、系统日志。
- [ ] **返回关系**：系统后台只有返回首页回业务数据首页，不和业务页混用导航。
- [ ] **角色边界**：che 看不到系统后台和平台后台；admin 可进系统后台但不可进平台后台；plat_admin 可进平台后台。
- [ ] **列表能力**：业务列合理、序号、勾选、收藏、表头排序、高级筛选、列设置、全部导出、导出选中、批量操作限制。
- [ ] **导入导出反馈**：导入有模板下载、字段匹配、预检查、错误行、任务状态和批次结果；导出有全部导出、导出选中、后台任务、完成消息和下载入口。
- [ ] **模块配置**：创建模块页包含基础信息、字段、列表、筛选、场景、页面动作、发布，且有真实控件。
- [ ] **打印模板配置**：模块配置内能看到模板列表、字段绑定、模板版本、打印预览、导出 PDF 和详情打印记录。
- [ ] **配置版本发布**：字段、列表、筛选、场景、动作、导入导出、打印模板有草稿/已发布、发布影响和回滚入口。
- [ ] **角色权限**：角色页包含成员分配、模块、字段、数据、动作权限和权限预览。
- [ ] **流程配置**：流程管理包含审批类型、触发事件、节点库、节点属性、流程模拟、审批人预览、版本快照、发布检查和错误态。
- [ ] **待办消息**：待办和消息都有来源、类型、状态、时间、关键词筛选，并能进入业务详情、任务结果或日志详情。
- [ ] **日志检索**：平台日志和系统日志都有时间、操作人、对象/模块、类型、来源、结果、IP、关键词筛选。
- [ ] **真实内容**：配置页没有 `名称1`、`类型1`、`说明1`、`角色1`、`参数映射1` 这类占位数据。
- [ ] **组织架构布局**：左侧是真部门树，宽度合理，右侧员工列表可扫描，不用 stepper 或卡片代替树。
- [ ] **流程画布**：流程节点有连线、箭头、条件分支标签、节点库和右侧属性面板，不是节点卡片网格。
- [ ] **导入导出交互**：运行态列表下方不常驻导入导出面板，导入导出通过弹窗/抽屉/下拉和任务反馈完成。
- [ ] **详情精细度**：详情右侧工作区贴顶贴底、宽度足够，tab 内容是专属业务数据，不复用权限矩阵。
