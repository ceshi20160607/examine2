## 审阅清单

- [ ] **四套壳分离**：平台工作台、平台后台、系统业务页、系统后台导航完全分开。
- [ ] **平台工作台**：顶部仪表盘、Flow、应用；右侧待办、消息、个人信息。
- [ ] **平台后台**：左侧平台信息、组织架构、角色管理、仪表盘管理、配置管理、日志管理。
- [ ] **系统业务页顶部**：参考 CRM 骨架，顶部展示系统/应用入口、仪表盘、模块分组、待办、消息、个人信息和工具图标，当前分组高亮。
- [ ] **业务分组布局**：点击模块分组后，左侧显示该分组下模块，右侧显示当前模块数据列表。
- [ ] **详情打开方式**：详情从右侧打开并保留左侧列表上下文，不做居中普通弹窗。
- [ ] **详情骨架**：详情顶部有模块标签、主标题、关键摘要、转移/编辑/删除/打印/更多按钮。
- [ ] **详情标签页**：车辆详情使用详细资料、维保记录、授权驾驶员、附件、打印记录、操作记录；其他业务模块使用各自专属 tab，不用通用矩阵凑内容。
- [ ] **详情审批面板**：详情右侧有审批流程信息、当前节点、处理人、历史流程入口和审批按钮。
- [ ] **系统后台**：左侧系统信息、组织架构、统一认证、角色管理、模块管理、工作配置、AI Agent 配置、流程管理、字典管理、仪表盘管理、数据源、对外应用、日志管理。
- [ ] **返回关系**：系统后台只有返回首页回业务数据首页，不和业务页混用导航。
- [ ] **角色边界**：che 看不到系统后台和平台后台；sys_admin_vehicle 可进系统后台但不可进平台后台；platform_member 只能进平台工作台和授权系统；platform_admin_root 可进平台后台。
- [ ] **系统切换**：顶部系统切换是唯一多系统入口，包含当前系统、角色、租户、进入/申请/禁用原因，切换后生成 SystemSwitchContext，刷新 systemId、tenantId、systemMemberId、有效角色、模块、字段权限、数据范围、待办和消息。
- [ ] **租户切换上下文**：多租户系统有 TenantSwitchContext，单租户隐藏租户切换；切换后刷新菜单、待办、消息、字段权限、数据范围和业务壳展示。
- [ ] **系统壳重绘**：从平台切换到不同系统时，品牌、顶部模块分组、左侧模块、列表数据、待办、消息和字段权限都随 accountMemberBindingId / systemMemberId 变化，不只是替换标题。
- [ ] **系统成员映射**：平台账号进入系统前必须有系统成员映射、系统角色和有效数据范围；平台内置超级管理员不能绕过系统权限直接看或改业务数据。
- [ ] **平台/系统消息边界**：平台消息中心和系统消息中心拆开；平台消息不能直接打开系统业务详情，系统消息只有在系统成员上下文内整条点击跳业务对象。
- [ ] **无权限访问**：隐藏菜单之外，直接访问无权限页面必须显示无权限态/403、缺失权限、当前角色、申请入口和 requestId。
- [ ] **模块组模型**：模块组只负责顶部分组、左侧组内模块、排序、可见角色和发布关系；业务数据归属 systemId/tenantId/moduleId，不按 appId 归属。
- [ ] **对外应用模型**：对外应用只负责 OpenAPI 接入来源、appKey/secret、scope、回调、限流和审计来源，不作为系统内模块父级。
- [ ] **平台授权边界**：平台普通成员只能查看/申请授权，不能新增或配置系统授权；平台授权配置只对平台管理员或授权管理员开放。
- [ ] **系统生命周期**：平台入口和创建系统承接中能看出创建系统、启用系统、停用系统、删除系统、恢复/禁用原因和审计边界。
- [ ] **企业 SSO 配置**：平台配置管理有统一认证 / 企业 SSO 身份源配置，覆盖 OIDC/SAML/OAuth2/LDAP、回调、证书/JWKS、域名白名单、属性映射、JIT、MFA 和测试发布；系统后台有一级“统一认证”页承接系统继承、域名范围、组织映射、员工绑定、JIT 系统成员策略、无成员映射反馈和登录日志 traceId。
- [ ] **SSO 与组织架构联动**：系统统一认证页能把外部部门映射到系统部门树，把 externalUserId/email/mobile/employeeNo 绑定到平台账号、系统员工和 systemMemberId；未匹配部门、未绑定员工有预检、草稿、人工确认和日志。
- [ ] **密钥引用与轮换**：SSO、OpenAPI、Webhook、外部模型等密钥使用 SecretRef，不回显明文；密钥轮换有 SecretRotationJob、双写验证、切换生效、失败回滚和审计。
- [ ] **OpenAPI 密钥引用**：外部应用只展示 OpenApiSecretRef、版本、轮换状态、到期和最近使用，不展示明文 appKey/secret。
- [ ] **列表主动作**：列表显式支持表头排序、列设置、整行点击打开详情；操作列不重复放详情。
- [ ] **行点击范围**：只有明确数据列表或业务核心列表显示整行点击手势；说明表、配置矩阵和普通状态表不伪装成可点击数据行。
- [ ] **列表能力**：业务列合理、序号、勾选、收藏、表头排序、高级筛选、列设置、全部导出、导出选中、批量操作限制。
- [ ] **批量与导出**：列表工具栏包含全部导出、导出选中、导入；勾选后才出现转移、删除、导出选中、批量编辑等批量操作，并按权限和状态禁用。
- [ ] **导入导出反馈**：导入有模板下载、字段匹配、预检查、错误行、任务状态和批次结果；导出有全部导出、导出选中、后台任务、完成消息和下载入口。
- [ ] **模块配置**：创建模块页包含基础信息、字段、列表、筛选、场景、页面动作、发布，且有真实控件。
- [ ] **字段类型覆盖**：模块配置中的字段类型库覆盖文本、多行文本、手机号、邮箱、身份证号、日期范围、级联选择、组织/租户、附件、图片、自动编号、关联数据、引用字段、子表、地理位置、评分、条码/二维码、富文本、JSON、密码/密钥、公式字段、汇总字段和 AI 填充字段。
- [ ] **打印模板配置**：模块配置内能看到模板列表、字段绑定、模板版本、打印预览、导出 PDF 和详情打印记录。
- [ ] **配置版本发布**：字段、列表、筛选、场景、动作、导入导出、打印模板有草稿/已发布、发布影响和回滚入口。
- [ ] **角色权限**：角色页包含成员分配、模块、字段、数据、动作权限和权限预览。
- [ ] **有效权限计算**：原型和 brief 明确多角色合并、显式拒绝优先、数据范围并集、字段权限与审批节点权限冲突处理、后端兜底。
- [ ] **有效权限返回结构**：有效权限详情包含 permissionVersion、sourceRoleIds、denyPolicyIds、dataScopeExpression、systemMemberId、字段权限矩阵、按钮禁用原因和解释链路。
- [ ] **流程配置**：流程管理包含审批类型、触发事件、节点库、节点属性、流程模拟、审批人预览、版本快照、发布检查和错误态。
- [ ] **流程高级运行策略**：转办、委托、加签、候选人领取、手动插入节点、子流程、外部 API 重试/补偿在原型中有配置和状态机样例。
- [ ] **流程快照**：流程绑定、优先级、互斥、幂等键、实例快照、任务快照和 traceId 已明确。
- [ ] **消息筛选与跳转**：消息中心是消息流，包含系统筛选、租户筛选、模板筛选，关联对象通过整条点击跳转，卡片内不堆重复小按钮。
- [ ] **消息状态操作**：消息筛选、全部已读、归档和整条跳转都有可见状态或结果反馈；平台消息不越权直跳系统业务详情。
- [ ] **消息模板与通知渠道**：消息、待办、审批、导入导出、Agent 结果有 templateCode、变量、渠道、跳转目标、去重键、已读回执、免打扰、失败重试和 message_delivery_log；平台模板不能直接跳系统业务详情。
- [ ] **待办消息**：待办和消息都有来源、类型、状态、时间、关键词筛选，并能进入业务详情、任务结果或日志详情。
- [ ] **日志分区**：平台和系统日志管理一个入口内区分登录日志和业务日志，二者各自有筛选、导出、详情和 traceId。
- [ ] **日志布局**：平台日志和系统日志都采用左侧日志类型/审计范围、右侧统一列表的组织架构式布局；左侧类型树是唯一主分类，右侧不再用日志类型下拉或页签重复分类。
- [ ] **日志检索**：平台日志和系统日志都有时间、操作人、对象/模块、类型、来源、结果、IP、关键词筛选。
- [ ] **日志审计字段**：日志详情显式包含 requestId、traceId、auditLogId、IP、设备、请求参数、字段前后值、错误原因、权限快照和脱敏结果。
- [ ] **真实内容**：配置页没有“名称/类型/说明/角色/参数映射 + 数字序号”这类占位数据。
- [ ] **组织架构布局**：左侧是真部门树，宽度合理，右侧员工列表可扫描，不用 stepper 或卡片代替树。
- [ ] **树节点交互**：组织树、角色树、模块树、字典分类和待办类型都能选择节点并刷新右侧列表/配置语义，不能只是静态左栏。
- [ ] **流程画布**：流程节点有连线、箭头、条件分支标签、节点库和右侧属性面板；条件、字段更新、外部 API、超时提醒等节点有专属属性承接，不是节点卡片网格或同一套审批表单。
- [ ] **流程画布宽度**：流程画布在 1440×900 下不裁掉节点；必要时使用最小画布宽度、横向滚动、缩放或折叠属性面板。
- [ ] **导入导出交互**：运行态列表下方不常驻导入导出面板，导入导出通过弹窗/抽屉/下拉和任务反馈完成。
- [ ] **详情精细度**：详情右侧工作区贴顶贴底、宽度足够，tab 内容是专属业务数据，不复用权限矩阵。
- [ ] **关键配置入口**：模块场景、页面动作、发布到业务页、工作字段、工作看板、流程类型、流程模拟、字典发布、AI Agent 发布检查都有可开发页面或抽屉，不只是 toast。
- [ ] **平台 Flow 专属设计**：平台 Flow 不复用通用说明抽屉，必须展示触发源、影响系统、节点连线、重试/补偿、运行批次、平台任务和 traceId。
- [ ] **注册初始化引导**：注册创建系统后进入系统后台初始化引导，能看到组织、角色、模块、字段、流程、字典、邀请成员和发布前检查。
- [ ] **关键运行操作**：流程节点属性、审批通过/驳回/转交/加签、AI 写入确认、导入导出、日志导出均有可开发抽屉或后台任务承接，不只是 toast。
- [ ] **关键按钮结果链路**：保存草稿、发布检查、审批处理、AI 写入、模板发布、密钥轮换、体检、恢复演练、部署策略等按钮有同步结果、后台任务、发布检查或日志追踪承接，不落到泛化“操作已响应”。
- [ ] **行操作去重**：列表整行点击为详情主动作后，操作列不再重复放“详情 / 查看 / 打开 / 进入”这类同义详情按钮，只保留配置、处理、编辑、更新、转移、导出、撤回、演练记录、风险复核等差异动作；只有明确标记的数据列表允许整行点击。
- [ ] **通用状态**：加载、空状态、无权限、错误状态、禁用状态、后台任务状态在原型和 brief 中有统一样例。
- [ ] **分页与按钮结果**：列表分页、上一页/下一页、加载更多、筛选应用、列设置保存、批量处理等按钮有明确状态变化或结果承接。
- [ ] **后台任务契约**：导入、导出、发布检查、流程模拟、AI 写入等长任务有 taskId、bizType、idempotencyKey、status、progress、resultFile/errorFile、traceId、auditLogId、失败明细和重试/回滚边界。
- [ ] **无成员申请对象**：认证成功但没有 systemMemberId 时形成 NoMemberAccessRequest，只有审核通过并分配角色/数据范围后才能从系统切换进入业务页。
- [ ] **无成员申请生命周期**：NoMemberAccessRequest 包含 requestId、status、identityProvider、externalUserId、targetSystemId、tenantId、requestRole、approverId、approveResult、roleIds、dataScope、rejectReason 和 traceId。
- [ ] **上线保障**：平台配置和系统信息页展示平台/系统体检、功能开关、灰度发布、容量配额、限流、备份恢复、归档恢复、最近备份、服务连通性和扩容申请。
- [ ] **运行效率入口**：系统业务页提供全局搜索、最近访问、快捷创建、表单草稿和错误字段定位，且受角色权限、字段脱敏和数据范围控制。
- [ ] **关键模板专属化**：流程节点属性、审批处理、AI 写入确认、字典发布检查、AI Agent 发布检查和通用状态样例都有专属模板结构，不依赖 default/generic 兜底。
- [ ] **default 阻断态**：defaultDrawer 只表示设计缺口阻断态，任何 P0 入口落到 default/generic 都不能进入 coding。
- [ ] **工作管理覆盖**：工作管理包含仪表盘、项目任务、普通任务、我的日报四个主标签；项目任务和普通任务支持列表/看板切换，日报只展示我的日报和筛选。
- [ ] **字典类型**：数据字典能按字典类型筛选，区分普通、树形、级联、状态、标签和字段选项字典。
- [ ] **AI Agent 分层**：平台级模型授权和系统级 Agent 策略已分开表达，系统级 Agent 受权限、脱敏和人工确认控制。
- [ ] **AgentPolicyScope**：系统 Agent 策略显式包含 moduleScope、fieldScope、actionScope、dataScopeExpression、外发限制、脱敏策略和策略版本。
- [ ] **AI Agent 运行边界**：平台工作台 Agent 只处理平台授权、日志、任务、模型额度、系统健康和系统切换引导，不直接打开系统业务列表/详情；系统 Agent 只能在系统切换后的当前系统成员上下文内处理业务数据。
- [ ] **AI Agent 确认边界**：平台 Agent 只确认生成平台任务、平台消息和平台日志；系统 Agent 才进入业务字段差异、审批、失败补偿和业务日志确认，二者不能共用同一个业务写入确认入口。
- [ ] **数据源与对外应用**：数据源覆盖数据库直连、系统内数据源、外部 API；对外应用覆盖 appKey、secret、scope、回调、限流和调用日志。
- [ ] **多环境与部署回滚**：平台配置和系统信息页能看到开发/测试/生产配置隔离、发布前备份、前端/后端/配置回滚、生产占位密钥检查和破坏性脚本确认。
- [ ] **API 规范与缓存策略**：原型有专属入口覆盖 requestId、traceId、分页筛选排序、错误码、幂等键、权限/字典/页面配置缓存 key 与失效规则。
- [ ] **移动效率入口**：收藏菜单、移动端扫码和拍照上传已进入运行态快捷创建/附件草稿链路，并明确权限、脱敏、失败重试和业务日志。
