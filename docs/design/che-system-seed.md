## 11. 流程（车辆档案）

| 项 | 值 |
|----|-----|
| 名称 | 车辆状态变更审批 |
| 触发 | 字段 `vehicle_status` 变更为 停用/报废 |
| 节点1 | 条件：状态 in (停用,报废) |
| 节点2 | 审批：角色=车辆主管 |
| 节点3 | 抄送：系统管理员 |
