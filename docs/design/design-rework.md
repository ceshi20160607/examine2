## 2026-06-15 v3.1 返工范围（RES-006）

### 现有 v3 遗漏

| 域 | 现有表现 | 需要补齐 |
|----|----------|----------|
| 业务数据列 | `runtime-list` 只有车牌、品牌型号、购置日期、驾驶员、状态、查看 | 增加归属部门、年检到期、最近维保、排序态、合理列宽与业务优先级 |
| 检索 | 快捷搜索 + 状态下拉 | 快捷搜索 + 高级筛选抽屉 + 保存为场景 |
| 场景 | 无场景入口 | 全部车辆、在用车辆、待年检、维保中、我负责的 |
| 设置 | 无列设置 | 显示/隐藏、顺序、列宽、固定列、保存我的表头 |
| 导出 | 单个导出按钮 | 全部导出 + 导出选中，分别说明作用范围 |
| 表头排序 | 下拉排序 | 表头排序入口和当前排序状态 |
| 序号/勾选 | 无 | 表头全选、行勾选、分页连续序号 |
| 批量限制 | 无批量条 | 选中后按权限和数据状态限制转移、删除、导出、批量编辑 |
| 详情 | 居中 modal | 右侧详情抽屉，行点击或详情按钮打开 |
| 建模配置 | 字段、动作、菜单、发布 | 列表列、筛选字段、列表场景、动作权限配置 |
| 平台配置 | `flow/apps` 是用户入口或占位 | 平台后台 `plat-admin-flow` / `plat-admin-apps` 配置页 |

### Open Design v3.1 输出

输出目录：`docs/design/prototypes/v3.1/`

必须生成：

- `index.html`
- `system/runtime-list.html`
- `system/admin-modeling.html`
- `platform/plat-admin-flow.html`
- `platform/plat-admin-apps.html`

### 验收断言

- `runtime-list` 首屏能看出这是车辆档案业务列表，而不是调试表。
- 不勾选时不能操作“转移、删除、导出选中、批量编辑”。
- 勾选后批量条出现，并展示至少一个禁用原因。
- “全部导出”始终在工具栏，按当前筛选/场景导出。
- 高级筛选、列设置、详情均为抽屉或侧边层，不挤压主表格。
- 建模页能解释运行态列表的列、筛选、场景、动作从哪里配置。

## 2026-06-15 v3.2 返工范围（RES-007）

### v3.1 截图暴露的问题

| 域 | 现有表现 | v3.2 调整 |
|----|----------|-----------|
| 顶部信息密度 | 标题摘要、场景条、搜索工具栏、批量条连续占多行 | 压缩为标题行 + 单行工具栏；选中条只在勾选后出现 |
| 场景 | 所有场景用胶囊横铺，占一整行 | 当前场景用下拉/分段控件，最多露出 2~3 个常用场景 |
| 搜索 | 搜索框和“快捷搜索”按钮重复占位 | 搜索框内置搜索行为，回车触发；高级筛选保留按钮 |
| 项目/系统选择 | 若单独做大区域会继续挤压表格 | 放在顶栏或标题行小下拉，不独占一行 |
| 新建入口 | 标题右侧和工具栏可能重复 | 全页只保留一个主按钮 |
| 批量限制提示 | 长句铺满页面 | selection bar 高度不超过 40px；禁用原因用 tooltip 或短句 |
| 表格首屏 | 控件占位过多，业务行偏少 | 1440×900 首屏至少 8 行 |
| 用户角色 | 成员与角色放同一页面 Tab | 系统成员/角色拆页；平台用户/角色也拆页 |

### Open Design v3.2 输出

输出目录：`docs/design/prototypes/v3.2/`

建议生成：

- `index.html`
- `system/runtime-list.html`
- `system/admin-modeling.html`
- `system/admin-users.html`
- `system/admin-roles.html`
- `platform/plat-admin-users.html`
- `platform/plat-admin-roles.html`
- `platform/plat-admin-flow.html`
- `platform/plat-admin-apps.html`

### 验收断言

- 车辆档案页第一屏以表格为主，不被场景、搜索、批量提示压住。
- 场景、搜索、高级筛选、列设置、导入、导出在同一条紧凑工具栏内完成。
- 不出现两个“新建”主按钮。
- 勾选前不显示批量条；勾选后出现紧凑 selection bar。
- 用户/成员管理与角色权限配置为独立页面、独立菜单。
- 平台角色不配置系统业务字段权限；系统字段权限只在系统角色页维护。
