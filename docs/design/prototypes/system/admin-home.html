欢迎使用系统后台

按以下顺序完成配置，即可让成员（如 che 陈和）在运行态使用车辆管理功能。

1

创建模块组

定义顶栏导航分组，如「车辆管理」。运行态顶栏将显示模块组名称。

前往模块组
2

添加组内模块

在模块组下创建业务模块：车辆档案、维保记录、驾驶员等。

前往模块
3

配置字段与页面

在建模页定义字段、列表页动作（含导出）、菜单结构。

前往建模
4

发布上线

检查发布清单并发布，成员即可在运行态看到最新配置。

查看发布清单

推荐配置路径

模块组 → 模块 → 字段 → 页面动作 → 菜单 → 发布
