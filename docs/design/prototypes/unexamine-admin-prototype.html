unexamine 可配置业务系统平台

以“车系统”为演示业务，覆盖平台层、系统运行态、系统后台三类边界。原型采用高密度企业后台布局，重点页面优先展示真实表格、筛选、权限状态和配置关系。

关键审阅页面
重点审阅车辆档案列表首屏表格、紧凑工具栏、选中条、右侧抽屉 重点审阅建模字段、列表、筛选、场景、页面动作、发布 重点审阅成员管理独立页面，成员来自平台用户 重点审阅角色权限模块/字段/数据/动作权限分区 边界审阅平台 Flow 配置平台级 Flow，不绑定单一系统模块 边界审阅系统对外应用系统级开放能力，不是模块容器
全部页面入口
登录前登录账号进入平台，待办和消息在登录后顶栏出现。 登录前注册并创建系统注册人自动成为新系统管理员，进入车系统配置引导。 平台工作台我的系统平台工作台首页，选择车系统或进入平台后台。 平台工作台待办列表跨系统待办汇总，侧栏不重复放待办菜单。 平台工作台消息列表系统通知和审批消息汇总，只从顶栏入口进入。 平台工作台平台 Flow 工作台平台级 Flow 入口，和系统 Flow 保持边界。 平台工作台平台应用入口开放平台能力和平台 Flow 的应用入口。 平台工作台平台日志平台工作台可见日志入口，不等同平台后台审计。 平台后台平台后台概览平台级账号、角色、Flow、应用与全局策略概览。 平台后台平台用户管理唯一登录账号来源，系统成员从平台用户中选择。 平台后台平台角色管理配置平台后台权限，不配置车系统字段权限。 平台后台平台 Flow 配置配置跨系统或平台级流程，可被平台应用授权开放。 平台后台平台应用配置AppKey 脱敏展示，授权平台 Flow 和平台能力。 平台后台平台后台日志审计平台后台操作，不混入普通业务日志。 平台后台平台全局配置登录安全、OpenAPI、文件存储、配额与功能开关。 系统运行态che 视角系统仪表盘普通成员只看运行态业务能力，不显示后台入口。 系统运行态admin 视角系统仪表盘系统管理员可见系统后台入口和配置健康状态。 系统运行态车辆档案列表重点业务列表：按权限显示新建按钮；行操作进入详情、编辑和更多动作。 系统运行态系统内审批处理车系统内审批任务处理，不进入平台 Flow 配置。 系统后台系统后台首页引导配置完成度、发布检查和下一步任务。 系统后台基础参数系统名称、图标、编码、域名和默认首页。 系统后台数据字典车辆状态字典及下拉字段关联。 系统后台数据源仪表盘统计卡绑定系统内或外部数据源。 系统后台仪表盘配置组件库、画布和属性面板发布运行态仪表盘。 系统后台模块组车辆管理模块组，组织运行态左侧模块导航。 系统后台模块车辆档案、维保记录、驾驶员模块管理。 系统后台建模字段、列表、筛选、场景、页面动作和菜单发布。 系统后台成员管理邀请、停用、分配角色；成员来自平台用户。 系统后台角色权限模块、字段、数据、动作权限分区配置。 系统后台流程配置绑定业务模块的系统 Flow 设计器。 系统后台系统对外应用授权外部系统访问当前系统内指定模块动作。 系统后台组织结构部门树和成员归属，支撑数据权限。 系统后台系统日志车系统配置和运行态业务操作日志。
