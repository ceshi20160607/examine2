## 2. 用户反馈落实

本轮针对 P19/P18 反馈做了明确修正：

- 顶部全局栏包含产品标识、当前上下文、全局搜索、审批、待办、消息、日志、切换系统、用户基础信息。
- 左侧只显示当前角色和当前工作空间菜单，支持收起；没有 `P / S / R` 原型切换器。
- 平台管理员、系统管理员、普通业务用户、集成管理员四类登录态有不同落点、导航和主操作。
- 系统数量上百上千时，通过“系统选择中心”搜索、筛选、分页和收藏，不把系统列表塞进左侧导航。
- 平台级 Flow 与平台级对外应用是同级能力，未合并。
- 系统内应用配置与流程事件绑定分开。
- 普通业务用户只看到工作台、待办、授权模块、文件/导出、消息和个人中心，不显示管理配置、权限、字段、页面发布和日志审计管理入口。
- 列表页包含搜索、高级筛选、列配置、保存视图、分页和行操作。
- 新建、编辑、详情类交互统一使用右侧抽屉。

## 3. Orchestrator 浏览器复核

已通过 in-app browser 打开 `http://127.0.0.1:4190/index.html` 复核：

- 默认平台首页：有顶部全局栏、平台工作区左侧导航，无 P/S/R 原型切换器。
- 用户菜单：可以切换到普通业务用户态。
- 普通业务用户态：左侧菜单不含成员/权限/字段/页面/流程绑定/日志审计管理入口。
- 普通业务用户右上待办：只显示车辆档案、司机任务等业务待办，不显示“页面发布失败处理”等配置任务。
- 车辆档案列表：从工作台卡片可进入，包含高级筛选、查询、列配置、保存视图、分页、详情、编辑、提交审批。
- 右侧抽屉：可打开，包含业务说明、最近追踪、操作历史、取消和保存。
- 平台侧术语：导航已显示“平台级对外应用”，不是模糊的“平台级应用”。
