# P17 低成本 UI 原型复核说明

状态：`draft-for-user-review`

更新时间：2026-06-13

## 1. 本轮目标

本轮不做最终视觉稿，不进入前端实现，不打包。目标是用低成本 HTML 原型先确认产品模型和主流程是否理解正确。

原型文件：

- `docs/ui/prototypes/p17-low-cost-ui-prototype.html`

本地预览：

- `http://127.0.0.1:4177/`

## 2. 已覆盖的关键理解

- “应用”只作为对外/跨系统调用管理主体，不再作为系统内模块或模块分组。
- 系统内对象使用“模块、字段、页面、菜单、运行台”等术语。
- 登录后按权限分流：平台管理态、系统管理态、普通业务运行台、多系统选择页。
- 左侧导航支持展开/折叠。
- 平台普通态、平台管理态、系统普通态、系统管理态分开展示。
- 新建、编辑、详情使用同一套右侧抽屉体系。
- 车辆档案列表包含高级筛选、表头配置、保存视图、分页和字段权限效果。
- 成员与权限包含页面权限、字段权限、动作权限、数据范围和权限效果预览。
- 应用中心表达 appKey/secret、授权系统、授权模块动作、流程、IP 白名单、限流、调用日志和 requestId 追踪。

## 3. 浏览器自检

已通过本地浏览器烟测：

1. 多系统用户登录进入系统选择页。
2. 选择“车”进入系统首页。
3. 切换到业务运行台。
4. 打开车辆档案高级筛选。
5. 打开车辆档案详情右侧抽屉。

## 4. 当前限制

- 这是低成本结构原型，不是最终视觉稿。
- 原型使用静态数据，未接入真实接口。
- 部分页面只表达关键结构，后续需要 UI/UX 继续细化页面状态、组件规范和视觉层级。
- 用户复核通过前，frontend 不得基于该原型进入最终实现。

## 5. 复核重点

请优先看以下问题是否已经对齐：

1. 应用、系统、流程、模块的概念是否摆正。
2. 多系统用户登录后的选择流程是否合理。
3. 平台管理、系统管理、普通运行台是否分得清楚。
4. 左侧导航、右侧抽屉、列表高级筛选和表头配置是否符合主流后台习惯。
5. 权限表达是否覆盖页面、字段、动作、数据范围和应用调用范围。
