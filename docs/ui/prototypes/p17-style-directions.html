P17 UI 风格方向选择

这不是最终页面，只用于选择视觉气质和后台框架方向。上一版低成本结构稿不是 Open Design 输出，是 Codex 手写的流程校正稿，视觉质量不达标。

已按新的架构理解重置：平台是统一登录入口加平台级能力中心；自建系统是业务后台配置空间；系统内应用配置用于使用平台级应用能力；模块和模块分组只负责业务页面和数据。
