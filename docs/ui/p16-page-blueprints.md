# P16 页面蓝图

状态：`frozen-for-implementation`

## 1. 登录页

- 左侧说明产品目标：建系统、搭业务、给普通用户使用、对外开放。
- 右侧是登录表单。
- 登录失败必须给出中文原因。
- 不展示接口地址配置面板。

## 2. 我的业务系统

页面目标：让用户创建业务系统或进入自己有权限的系统。

布局：

- 顶部：标题“我的业务系统”，主按钮“创建业务系统”。
- 操作面板：系统名称、编码、租户模式、说明。
- 列表：系统名称、租户模式、状态、我的身份、进入系统。
- 空态：平台管理员提示创建系统，普通用户提示联系管理员加入系统。

## 3. 系统首页

页面目标：告诉系统管理员或普通用户下一步该做什么。

布局：

- 顶部显示当前系统、租户、成员和权限摘要。
- 管理员看到配置进度：成员、角色、业务应用、模块、字段、发布。
- 普通用户看到业务运行入口和自己可用模块状态。
- 快捷入口按权限显示。

## 4. 成员与权限

页面目标：系统管理员不离开当前系统即可开通成员。

布局：

- 主按钮“开通成员”。
- 操作面板字段：登录账号、姓名、初始密码、部门、岗位、角色、租户。
- 成员列表：成员、登录名、部门、角色、状态、操作。
- 详情入口展示成员上下文、角色、数据范围和字段权限。

## 5. 建模配置

页面目标：把业务对象发布成普通用户可使用的模块。

流程：

1. 业务应用。
2. 模块。
3. 字段。
4. 页面与菜单。
5. 发布检查。
6. 发布到业务运行台。

每一步必须有当前步骤、下一步、发布检查结果和错误定位。

## 6. 业务运行台

页面目标：普通业务用户处理业务数据。

布局：

- 顶部：当前系统、数据范围说明、主按钮“新增记录”。
- 左侧或上方：被授权模块入口。
- 列表：业务标题、状态、创建人、更新时间、操作。
- 新增/编辑：抽屉或可折叠操作面板，按字段权限渲染。
- 详情：字段详情、流程、附件、历史、操作日志。
- 空态：说明当前没有授权模块或没有数据。

## 7. 对外应用中心

页面目标：让外部系统可控接入。

流程：

1. 创建对外应用。
2. 生成 appKey/secret，secret 只展示一次。
3. 授权系统、模块、字段、动作、数据范围。
4. 配置 IP 白名单、限流、过期和签名策略。
5. 查看调用示例和 requestId 日志。

## 8. 审计与运维

页面目标：按 requestId 追踪问题。

布局：

- 查询区：requestId、日志类型、业务对象、结果。
- 列表：请求号、操作人、业务、结果、时间。
- 详情：API、trace、操作者、变更字段、快照、错误码。
