# P16 组件与交互规范

状态：`frozen-for-implementation`

## 1. 操作面板

- 新建、编辑、授权、导入、上传等写操作必须放在主按钮触发的面板中。
- 当前首轮实现采用可折叠操作面板，后续可替换成抽屉或独立页面。
- 面板默认收起，避免页面首屏像表单堆叠。
- 面板标题必须使用业务动作，例如“创建业务系统”“开通成员”“新增记录”。

## 2. 列表

- 列表必须显示标题和当前记录数。
- 列表必须包含空态。
- 分页列表必须显示总数、当前页和上一页/下一页。
- 行内操作只放常用动作，复杂信息进入详情。

## 3. 表单

- 标签使用中文业务语言。
- 技术 ID 默认不作为主要字段展示，必要时放到详情或诊断区。
- 可写、只读、隐藏字段必须按字段权限渲染。
- 危险动作必须二次确认或给出影响说明。

## 4. 状态

- 加载中、空态、错误态、权限不足、服务异常必须有中文说明。
- 错误提示要包含 requestId，方便审计追踪。
- 成功后要说明下一步。

## 5. 视觉

- 使用清晰、克制的企业级后台风格。
- 主色用于主按钮、当前导航和关键状态，不大面积铺底。
- 页面区域不嵌套过多卡片。
- 字号固定，不随 viewport 缩放。
