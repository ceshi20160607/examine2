## 1. 工作空间

P16 使用四个清晰工作空间，不再把所有能力混成一个后台菜单。

| 工作空间 | 用户 | 目标 |
| --- | --- | --- |
| 平台工作空间 | 平台管理员、集成管理员、审计/运维 | 创建业务系统、维护平台账号和角色、管理平台级对外应用、查看平台日志和运维状态 |
| 系统管理工作空间 | 系统管理员、配置管理员 | 在当前业务系统内开通成员、配置权限、搭建模块、发布页面、授权系统能力 |
| 业务运行工作空间 | 普通业务用户 | 只处理自己被授权的业务模块和数据 |
| 集成开放工作空间 | 集成管理员 | 创建对外应用、授权系统数据/动作/字段/数据范围、追踪调用日志 |

## 2. 默认落点

- 平台管理员登录后进入“我的业务系统”，可以创建或进入业务系统。
- 系统管理员进入某个系统后落到“系统首页”，页面告诉下一步配置什么。
- 普通业务用户如果只属于一个系统，直接进入该系统“业务运行台”；如果属于多个系统，先选择业务系统。
- 集成管理员优先看到“对外应用中心”和可授权系统。

## 3. 导航分层

平台层：

- 我的业务系统
- 平台管理：业务系统、平台账号、平台角色、平台配置
- 对外应用中心
- 平台审计
- 运维诊断

系统层：

- 系统首页
- 成员与权限：成员、部门、角色、字典
- 建模配置：业务应用、模块、字段、页面与发布
- 业务运行
- 协同与文件：流程、文件、导出
- 系统对外授权
- 系统审计

普通业务用户层：

- 业务运行首页
- 被授权业务模块
- 待办、文件、导出等被授权入口
- 退出

## 4. 页面结构统一规则

每个真实业务页面必须按以下结构组织：

1. 页面标题和当前上下文。
2. 主操作区，使用主按钮或可折叠操作面板承载新建、编辑、导入、授权等动作。
3. 筛选区，放关键字、状态、模块等查询条件。
4. 列表区，包含表头、记录数、空态和分页。
5. 详情区或详情入口，用详情页、抽屉或详情分区承载完整信息。
6. 反馈区，显示成功、失败、requestId 和恢复建议。

## 5. P16 首轮实现策略

为避免继续扩散旧页面，P16 首轮实现先完成全局结构升级：

- 所有常驻大表单统一改为可折叠操作面板。
- 所有列表统一显示列表标题、当前记录数和分页语义。
- 页面壳层强化当前账号、当前系统、当前成员和退出入口。
- 普通业务用户的导航继续按权限过滤，仅展示运行台和授权模块。
