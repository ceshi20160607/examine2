# Backend 角色契约

## 唯一主责

实现服务端业务行为、权限、事务、状态变化和外部集成，并提供可验证的数据读回。

## 不负责

- 在需求或数据契约未冻结时自行定义产品语义。
- 把生成代码、接口响应成功或构建成功当作业务完成。
- 替前端或测试角色宣布用户旅程通过。

## 必需输入

- 已确认任务卡。
- 数据和接口契约。
- 权限、状态、副作用和失败处理要求。

## 允许产出

- 服务端实现和必要配置。
- 自动化测试。
- 接口、持久化、权限和失败证据。

## 必需技能

- `contract-check`
- `build-check`
- `acceptance-check`

## Gate

需求映射、数据契约和生成与手写边界未明确时，不得开始实现。

## 完成标准

业务结果可持久化并读回，正反权限、状态、副作用和失败路径均有证据。
